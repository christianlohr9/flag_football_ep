<objective>
Two training-side prerequisites that must exist before M3-02-05 can fit anything on the enlarged
corpus. Neither touches the ingest reader (M3-02-01's territory, same wave).

1. **Decouple the label sentinel from the model feature.** M3-02-01 sets `half = 2` for head-coach
   rows because that is the only value that keeps `_mark_half_end`'s `game_end`, WP's `Winner` and
   EP's post-game `None`-ing correct (M3-02-RESEARCH section 2.2). Feeding that same `2` into
   `EP_FEATURES` would make every head-coach row informationally identical to a genuine second-half
   play in the one feature the 1.3 adoption measurement (+0.001790 pooled log-loss) was based on.
   Overwrite it with a distinct integer sentinel for head-coach rows immediately before feature
   selection, so the model can learn "unknown half" as its own signal (RESEARCH section 2.3, flagged
   `[ASSUMED]`). Pin the label-construction chain with tests at the same time, because
   `prepare_wp_data` also calls `_mark_half_end` and CONTEXT's "half is EP-only" framing does not
   cover that (RESEARCH Pitfall 1).

2. **Close the competition-tier gap.** `data/reference/competition_tier.csv` has three rows and
   none of them matches any `hc_workbook` source. `reference.map_competition_tier` never lets a null
   `competition_tier` through — it raises `UnmappedCompetitionError`. The failure fires inside
   `train_ep`/`train_wp`, not at ingest time, i.e. after a potentially long LOGO fit has started
   (RESEARCH Pitfall 3 and section 5.4 — a gap found this session, not previously documented).

Purpose: without (1) the head-coach corpus silently degrades a measured EP feature; without (2) the
first `ffep train` on the enlarged corpus dies opaquely partway through.
Output: `src/flag_football_ep/features/mutations.py`, `tests/test_features_mutations.py`,
`data/reference/competition_tier.csv`, `tests/test_model_train.py`.
</objective>

```python
def _mark_half_end(df: pl.DataFrame) -> pl.DataFrame:
    return df.with_columns(
        half_end=(pl.col("index") == pl.col("index").max().over(["game_id", "half"]))
        .cast(pl.Int32)
    ).with_columns(
        game_end=pl.when((pl.col("half_end") == 1) & (pl.col("half") == 2))
        .then(pl.lit(1))
        .otherwise(pl.lit(0))
    )
```

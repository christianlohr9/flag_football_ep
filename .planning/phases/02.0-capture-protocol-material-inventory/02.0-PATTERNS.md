## Shared Patterns

### DEFERRED-ANALYST block
**Source:** `docs/data-contract.md` lines 167-169 (prose) and `docs/data-contract.schema.json` lines 4-13 (machine-readable mirror)
**Apply to:** `docs/capture-protocol.md` (agreement to the Wunschzettel), `docs/material-inventory.md` (inventory rows only the analyst can supply), `docs/sync-convention.md` (Variant A / Hudl-upload)
```markdown
> DEFERRED-ANALYST: Gespräch auf unbestimmte Zeit verschoben (User-Entscheid 2026-08-17).
> Owner: Nutzer. Follow-up-Trigger: sobald der Videoanalyst wieder verfügbar ist,
> spätestens vor dem nächsten Filmtausch. Zu ratifizieren: (a) ..., (b) ..., (c) ...
```
Keep "Owner: Nutzer" — the user, not the analyst, owns the follow-up trigger (matches D-01). Adapt the `(a)/(b)/(c)` list per deliverable: e.g. for `docs/capture-protocol.md` → "(a) Zustimmung zum Wunschzettel als praktikabel, (b) Machbarkeit von Akku-Wechsel-Timing"; for `docs/sync-convention.md` → "(a) Bereitschaft, Drohnenmaterial wie Spielfilm in Hudl hochzuladen und pro Play zu schneiden (Variante A)".

### Maintained-CSV dialect (comma, UTF-8, no BOM)
**Source:** `docs/data-contract.md` line 31 ("Dialekt-Dualität"); verified against `data/reference/*.csv` files directly
**Apply to:** `video_inventory.csv`, `video_sync.csv`

Bewusste Dialekt-Dualität: Handgepflegte Repo-CSVs (`data/half_boundaries.csv`, `team_roster.csv`)
verwenden schlichtes Komma + UTF-8 ohne BOM; **nur** Hudl-Exporte verwenden `;` + BOM.

State this explicitly in `docs/material-inventory.md` and `docs/sync-convention.md` so a future contributor doesn't apply the Hudl export dialect to these hand-maintained files.

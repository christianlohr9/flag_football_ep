- **Found during:** Task 1 (Dependencies, Python floor and packaging metadata)
- **Issue:** With no `.python-version` file and `requires-python = ">=3.12"` (no ceiling), `uv sync` selected the newest installed interpreter (CPython 3.13.3). `pyarrow==17.0.0` has no prebuilt wheel for cp313, so uv fell back to a source build, which failed (`ModuleNotFoundError: No module named 'pkg_resources'` inside setuptools' build-isolation venv).
- **Fix:** Added a `.python-version` file containing `3.12` (an interpreter already installed at `/opt/homebrew/bin/python3.12`, matching PROJECT.md's documented runtime: "Python 3.12 managed with uv"). Removed the stale `.venv` and re-ran `uv sync`, which succeeded and installed `pyarrow==17.0.0` from a prebuilt wheel.

- **Verification:** `uv sync` exits 0; `uv run python -c "import typer, mlflow, xgboost, polars, requests"` and `uv run pytest --version` both exit 0.

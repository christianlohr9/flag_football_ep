### `src/flag_football_ep/ingest/hudl.py` (service, file-I/O + transform)

**Analog:** `Python/helper_add_hudl_mutations.py`

**Imports pattern** (lines 1-2):

**Core transform pattern — home/away + posteam/defteam derivation** (`get_games`, lines 4-12; `make_hudl_mutations` opening join, lines 21-27):
```python
def get_games(df: pl.DataFrame):
    games = (
        df.melt(id_vars="game_id", value_vars="posteam")
          .unique(maintain_order=True)
          .pivot(values="value", index="game_id", columns="variable", aggregate_function=pl.element())
          .with_columns(pl.col("posteam").list.to_struct()).unnest("posteam")
          .rename({"field_0": "home_team", "field_1": "away_team"})
          )
    return games

output = (
    df.join(get_games(df), on="game_id")
    .with_columns(defteam =
                pl.when(pl.col("posteam") == pl.col("home_team")).then(pl.col("away_team"))
                .when(pl.col("posteam") == pl.col("away_team")).then(pl.col("home_team"))
                .otherwise(pl.lit(None))
                )
```
**IMPORTANT — do not port `get_games()`'s home/away heuristic as-is into `ingest/hudl.py`.** CONTEXT/RESEARCH both flag this as a "known-fragile precedent" ("the team with the first drive is home"). New-format Hudl ingest must instead implement the contract's TEAM1/ODK-derived `posteam` rule (`docs/data-contract.schema.json` → `filename_semantics`: "posteam = TEAM1 wenn ODK == ..."). Keep `get_games()` only inside `ingest/legacy.py` for `data_raw.csv`.

**RESULT-token derivation pattern (fix required)** — current substring-match code (lines 48-54, 56-93) is the anti-pattern to replace, not copy verbatim:
```python
# CURRENT (fragile, do not port as-is into ingest/hudl.py):
pl.when(pl.col('RESULT').str.contains("Rush")).then(pl.lit("run"))
.when(pl.col('RESULT').str.contains("Penalty")).then(pl.lit("no_play"))
.when(pl.col('RESULT').str.contains("KNEEL")).then(pl.lit("qb_kneel"))
```
Replace with exact-token match after `.str.split(", ")` per `docs/data-contract.md` RESULT grammar (see Pitfall 2 in RESEARCH). The surrounding shape (down/distance cast, yardline_50_simple bins, scoring/points/score-cumsum chain, lines 34-179) ports intact — only the RESULT-parsing predicate needs the exact-token fix.

**Score-cumsum pattern (port as-is)** (lines 130-166):
```python
.with_columns(
```

**Apply to:** `ingest/hudl.py`, `ingest/legacy.py`, `ingest/sportapp.py`, `ingest/ifaf.py` — do not attempt one generic "parse play outcome" function across sources; each source's raw vocabulary is source-specific (RESULT tokens vs. `action_title`/`summary` regex vs. cpx.studio's `outcome`/`description`). Convergence happens only at the canonical column contract.

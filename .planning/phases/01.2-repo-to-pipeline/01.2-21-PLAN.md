<objective>
Stop `add_score_columns` from silently zeroing a score that happens on a game's first play.

Purpose: closes Warning WR-02. The `pl.when(pl.col("play_id") == 1).then(pl.lit(0))` branch is evaluated before the scoring branch, so a kickoff-return touchdown or an opening safety contributes 0 points. That corrupts the game's whole cumulative score, `score_differential` and the WP `Winner` label, and makes `score_reconstruction` FAIL — quarantining a perfectly valid game. The grandfathered WC24 corpus alone contains 7 games whose first play carries a `scoring_play_team` (measured during planning), so this is a live failure mode for the fresh sportapp path, not a hypothetical.
Output: a correct precedence order in `add_score_columns`, tests pinning it, and a documented equivalence outcome.
</objective>

**Six per-game REQ-S1-05 checks (downs, yardline, half, monotonic drive IDs, gapless play IDs, score reconstruction) feeding a quarantine partition and quarantine-first Markdown report, built with polars group_by aggregation instead of row loops.**

## Accomplishments
- `checks.py`: six per-game validation checks (`downs_range`, `yardline_range`, `half_assigned`, `monotonic_drive_ids`, `gapless_play_ids`, `score_reconstruction`), each returning one `CheckResult` per `game_id`, registered in `CHECKS` in report order, driven by `run_checks`.
- `partition_games`: quarantines new-format games with any FAIL, downgrades FAIL to WARN (never mutating input results) for `warn_only_sources` (legacy by default), asserts row conservation with a `RuntimeError` guard, and raises `ValueError` on a game with inconsistent `source` values.
- `report.py`: `render_report` (pure string rendering, quarantine-first layout, summary table with one column per check, missing-reference section), `write_report` (writes both the timestamped and `-latest` files), `console_summary` (one line per game plus a tally, safe on an empty list).
- 47 new tests across both modules (33 in `test_validation_checks.py`, 14 in `test_validation_report.py`), all green; full repo suite (81 tests) green.

## Decisions Made
- **score_reconstruction team alignment:** compares `{frame_home, frame_away}` against `{ref_home, ref_away}` as sets before comparing scores, so a swapped or wrong home/away convention is reported as `"home/away convention mismatch"` rather than silently producing a wrong-score FAIL. This directly implements the plan's explicit requirement to not compare positionally.
- **Warn-only downgrade never mutates input `CheckResult` objects** — `partition_games` builds new `CheckResult(status=Status.WARN, ...)` instances for downgraded checks, per the plan's explicit "do not mutate" rule; this keeps `run_checks`' output reusable by callers that want the raw FAIL view.
- **Report layout is a fixed, hardcoded section order** (not configurable) since the plan explicitly mandates quarantine-first for operator scanning; this trades flexibility for a stable, testable contract.

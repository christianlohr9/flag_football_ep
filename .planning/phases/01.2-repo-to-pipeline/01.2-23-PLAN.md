Fix the two remaining cross-source data-correctness defects in the canonical merge: IFAF defensive two-point conversions credited to the wrong team, and a `play_type` column whose vocabulary differs by source.

Purpose: closes Warnings WR-03 and WR-11, both of which undermine REQ-S1-06's "one canonical schema" guarantee that VERIFICATION truth 3 flagged as caveated. WR-03 corrupts the score chain and can trip `score_reconstruction` for a whole IFAF game; WR-11 means any downstream filter on `play_type == "run"` silently drops every sportapp run play — the exact class of silent cross-source bug the canonical schema exists to prevent.
Output: correct defensive-conversion routing, one `play_type` vocabulary, and a cross-source contract test that fails if a source ever invents its own value again.
</objective>

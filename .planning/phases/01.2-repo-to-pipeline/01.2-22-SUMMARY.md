# Phase 01.2 Plan 22: Operator-visible ingest notices Summary

**Every dropped or degraded ingest source is now named in the Markdown report's Source notices/Skipped files sections, echoed on the console, and echoed by both `ffep ingest` and `ffep run`.**

## Performance

- **Duration:** ~25 min
- **Completed:** 2026-08-17
- **Tasks:** 3 completed
- **Files modified:** 5

## Accomplishments
- `render_report` gained a `## Source notices` section (source-level messages, always rendered with `None.` when empty) and a `## Skipped files` section (per-game notice keys with no matching `GameResult`, e.g. a Hudl file skipped with `df=None`) — closes the reporting half of CR-02 and WR-01.
- `run_ingest` now passes its collected `notices` list into `render_report` as `source_notices`, and echoes every one of them to the console (`notice: {text}`) right after `console_summary`, so a zero-game run (every source dropped) no longer prints nothing.
- `cli.ingest` and `cli.run` echo `result.notices` / `result.ingest.notices` respectively, so the operator sees the same notices at the CLI without opening the report file.
- End-to-end test group proves a wrong-delimiter Hudl file does not drop the source (clean game's rows still land in `plays.parquet`, broken file named under Skipped files), a missing source directory produces matching notices in the report and `IngestResult.notices`, the CLI prints a `notice:` line and exits 0, and a malformed `DN` cell degrades to a reported `downs_range` FAIL instead of dropping the game.

## Files Created/Modified
- `src/flag_football_ep/validation/report.py` - `render_report` gained an optional `source_notices` keyword param, a `## Source notices` section (after Quarantined games), a `## Skipped files` section (after Missing reference data, listing per-game notice keys with no matching `GameResult`), and a `Source notices: {n}` metadata bullet
- `src/flag_football_ep/pipeline.py` - `run_ingest` passes `source_notices=notices` into `render_report` and echoes each source notice (`notice: {text}`) via `typer.echo` after `console_summary`; docstrings updated to describe the new order of operations
- `src/flag_football_ep/cli.py` - `ingest` echoes `result.notices` after the existing three lines and before the `--strict` exit check; `run` echoes `result.ingest.notices` right after the `ingest:` line
- `tests/test_validation_report.py` - tests for the new sections, four-positional-arg backward compatibility, the metadata count bullet, and rendered section order
- `tests/test_pipeline_ingest.py` - end-to-end tests: wrong-delimiter containment + report visibility, missing-source report/notices parity, CLI notice output + exit code, malformed-`DN`-cell containment with a reported `downs_range` FAIL

## Decisions Made
- Chose to echo source notices directly from `pipeline.run_ingest` via a module-level `typer` import (mirroring `console_summary`'s existing use of `typer.echo`) rather than extending `console_summary`'s signature — keeps `console_summary`'s responsibility (per-game console lines) unchanged and avoids a signature change that would ripple into its existing tests.

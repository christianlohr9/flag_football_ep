# Phase 01.2 Plan 04: Canonical Plays Schema and Shared Derivations Summary

**Canonical plays schema (68 columns, core-plus-nullable-extras) in `canonical.py` with `conform_to_canonical`, a precedence-bug-fixed `add_scoring_play_team`/`add_score_columns` chain, and a schema-derived `canonical_plays()` test-frame factory in `testing.py`.**

## Accomplishments
- `src/flag_football_ep/canonical.py` defines `CORE_COLUMNS` (42 columns), `NULLABLE_EXTRAS` (26 columns), `NON_NULL_COLUMNS`, and `CANONICAL_COLUMNS` (68 total, `source` first) as the single, code-defined canonical schema every ingest source converges on.
- `conform_to_canonical(df, source)` fails hard with `MissingCanonicalColumns` listing every missing core name, materializes absent extras as typed nulls, casts every column non-strictly while counting newly introduced nulls into `ConformReport.cast_failures`, stamps `source`, and drops+reports unknown columns via `select(CANONICAL_COLUMNS)`.
- `add_scoring_play_team`/`add_score_columns` port the notebook's scoring-credit and score-accumulation chain as shared, per-game-safe code, fixing the original's `|`-then-`==1` operator-precedence bug and making defensive scoring credit (`def_touchdown`, `defensive_two_point_conv`, `safety`) switchable per source via `credit_defense`.
- `src/flag_football_ep/testing.py` gives every later plan's test module a `canonical_plays()`/`canonical_plays_with_scores()` factory built directly from the schema constants, with `overrides`/`extras` support and `ValueError` on misuse.
- 30 tests in `tests/test_canonical.py`, all green.

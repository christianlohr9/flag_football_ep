<objective>
Make every ingest notice operator-visible: in the Markdown report, on the console, and in the CLI.

Purpose: closes the reporting half of Critical finding CR-02 plus Warning WR-01 (VERIFICATION gap 2). `run_ingest` collects `notices` (source aborted, directory missing, legacy-sportapp loaded, IFAF game skipped) into `IngestResult.notices`, but that list is never passed to `render_report` (pipeline.py:413 passes only `game_notices`) and never echoed by `cli.ingest` (cli.py:47-49). `game_notices` entries for Hudl files skipped with `df=None` key games that have no `GameResult`, so they are silently dropped from the report too. A dropped or degraded source therefore produces zero output in the report, zero on the console and zero in the CLI.
Output: a "Source notices" section, a "Skipped files" section, CLI echo, and an end-to-end test proving a malformed export is contained AND visible.

Depends on plan 20, which supplies the containment this plan makes visible — the end-to-end test asserts both halves together.
</objective>

| notice strings → rendered artifact | notice text is interpolated from file paths, game ids and exception messages into a file the operator reads and may share |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-1.2-47 | Repudiation | an entire source silently missing from `plays.parquet` with no record anywhere | mitigate | `run_ingest` passes its source notices into `render_report`, the report always renders `## Source notices` (with `None.` when empty), and both CLI commands echo `result.notices` |
| T-1.2-48 | Repudiation | a skipped file's notice dropped because its game_id has no `GameResult` row | mitigate | `## Skipped files` renders every notice key with no matching `GameResult` |
| T-1.2-49 | Information Disclosure | a secret or absolute home path leaking into the shared Markdown report via a notice string | mitigate | notices are echoed verbatim from strings built only from configured paths, file names, game ids and exception class names; the module docstring's no-secrets rule is restated and no new interpolation is introduced |
| T-1.2-50 | Denial of Service | a zero-game run printing nothing at all, leaving the operator to assume success | mitigate | source notices are echoed after `console_summary`, which prints nothing when `game_results` is empty |

No new dependencies are installed by this plan, so no package-legitimacy checkpoint applies.

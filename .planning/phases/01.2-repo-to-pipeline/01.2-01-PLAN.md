Create `src/flag_football_ep/cli.py` with `app = typer.Typer(no_args_is_help=True, add_completion=False, help="flag-football EP/WP pipeline")` and exactly these commands (option names are the contract; every command takes `--config` defaulting to `ffep.toml`):

- `ingest` — options: `--config PATH`, `--source TEXT` (repeatable, default all of hudl, legacy, sportapp, ifaf), `--out PATH` (optional override of the processed dir), `--strict/--no-strict` (default no-strict). Delegates to `pipeline.run_ingest(config, sources, out_dir, strict)`.
- `fetch-sportapp` (function name `fetch_sportapp`) — options: `--config PATH`, `--game-ids TEXT` (comma-separated), `--games-file PATH`, `--force/--no-force`. Resolves game ids from `--game-ids`, else `--games-file`, else `config.reference.sportapp_games`; resolves the API key from the env var named by `config.sources.sportapp.api_key_env`. Delegates to `fetch.sportapp.fetch_games(...)`.
- `fetch-ifaf` (function name `fetch_ifaf`) — options: `--config PATH`, `--tournament TEXT` (default from config), `--game-id TEXT` (optional single game), `--limit INT` (default 500), `--force/--no-force`. Delegates to `fetch.ifaf.fetch_tournament(...)`.
- `train` — options: `--config PATH`, `--model TEXT` (one of ep, wp, both; default both), `--tune/--no-tune` (default no-tune), `--max-evals INT` (default 100), `--export-pkl/--no-export-pkl` (default no). Reads the canonical Parquet at `config.paths.processed / "plays.parquet"` with polars, then calls `model.train.train_ep` and/or `train_wp`.
- `score` — options: `--config PATH`, `--ep-run TEXT`, `--wp-run TEXT`, `--out PATH`. Reads the canonical Parquet, calls `model.score.score_plays(...)`, writes the returned frame to `--out` or `config.paths.processed / "plays_scored.parquet"`.
- `run` — options: `--config PATH`, `--skip-fetch/--no-skip-fetch` (default skip-fetch true, because snapshot-first ingest reads from disk), `--tune/--no-tune`. Delegates to `pipeline.run_all(config, tune)`.

Rules for the command bodies:
- Import stage modules INSIDE the function body (lazy import), never at module scope. Later plans create those modules; `ffep --help` and every `ffep <cmd> --help` must work before they exist.
- Every command starts by calling `flag_football_ep.config.load_config(config)` (also a lazy import).
- Validate `--model` against {ep, wp, both} and raise `typer.BadParameter` on anything else.
- Never print or interpolate a resolved API key. When echoing a URL, pass it through the redaction helper that plan 07 provides; in this plan just avoid printing secrets at all.
- End the module with the `if __name__ == "__main__": app()` guard.

`pipeline.run_all(config, tune=False) -> RunAllResult`
- Chains `run_ingest(config, ["hudl", "legacy", "sportapp", "ifaf"])` → `train_ep` → `train_wp` → `score_plays`, reading `plays.parquet` back from disk between ingest and training.
- Raises `EmptyIngestResultError` when ingest produced zero accepted plays.
- `RunAllResult` fields: `ingest` (an `IngestResult`), `ep_run`, `wp_run`, `scored_path`, `durations` (keys "ingest", "train_ep", "train_wp", "score").
- Writes the scored frame to `config.paths.processed / "plays_scored.parquet"`.

The null-feature shape to reproduce
- `ingest/ifaf.py` emits rows whose `yards_to_go` is null by design; `yardline_50` and `yards_to_go` are both EP features, and `WP_FEATURES` includes `yards_to_go`, `yardline_50`, `score_differential`, `down`, `receive_2h_ko`, `half_seconds_remaining`, `game_seconds_remaining`, `Diff_Time_Ratio`.
- `score_plays` scores a row with any null feature as null probabilities and preserves row count (T-1.2-18) — the mixed corpus must therefore still yield non-null `epa`/`wpa` on the COMPLETE rows.

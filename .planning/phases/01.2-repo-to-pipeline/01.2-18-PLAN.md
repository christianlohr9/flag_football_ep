<objective>
Stop `score_plays` from computing `epa`/`wpa`/`ep` on a chronologically scrambled frame.

Purpose: closes Critical finding CR-01 (VERIFICATION gap 1). `_score_probabilities` splits the frame into complete/incomplete subframes and returns `pl.concat([complete, incomplete])`, moving every null-feature row to the tail. `add_ep_variables`/`add_wp_variables` are order-dependent (`shift(-1)`, `backward_fill()`) and run on that reordered frame; the final row-id join restores output order but not the already-corrupted values. Every IFAF row has a null `yards_to_go` by design, so any run that merges IFAF (which REQ-S1-06 requires) silently produces wrong EPA/WPA.
Output: an order-preserving `_score_probabilities` plus regression tests that fail against today's implementation.
</objective>

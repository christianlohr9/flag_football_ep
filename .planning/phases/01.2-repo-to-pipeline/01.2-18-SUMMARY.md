# Phase 01.2 Plan 18: Fix scrambled-frame EPA/WPA scoring (CR-01) Summary

**`_score_probabilities` now returns rows in strict `_score_row_id` order via an explicit sort, closing the silent EPA/WPA corruption that every IFAF-containing scoring run triggered because null-`yards_to_go` rows were relocated to the frame tail before `add_ep_variables`/`add_wp_variables`'s order-dependent `shift(-1)`/`backward_fill()` ran.**

## Accomplishments
- `_score_probabilities` sorts its complete/incomplete concat on `_score_row_id` before returning, so `add_ep_variables`/`add_wp_variables` always see chronological order regardless of which rows had null features.
- `_score_probabilities` now raises `MissingScoreColumns` (naming `_score_row_id`) if that column is absent, instead of silently returning a reordered frame.
- Four new regression tests pin the CR-01 failure mode: an order-contract test on `_score_probabilities` directly, EP/WP backfill-from-next-play tests on a null-`yardline_50` row, and a cross-game non-regression test.
- Verified all four regression tests are discriminating: temporarily reverted the `.sort(_ROW_ID_COLUMN)` locally (not committed) and confirmed Test 1 (order), Test 2 (EP backfill) and Test 3 (WP backfill) fail; Test 4 (cross-game) correctly stays green either way since it only covers unaffected games.

## Task Commits

_Note: Task 2 is `tdd="true"`; the RED phase (confirming the tests fail without Task 1's fix) was verified by temporarily reverting the sort in a working-tree-only change, not by committing a failing test first, since Task 1 (the fix) is a separate, already-committed task in this plan. Both the temporary revert and its restore were verified against the full local diff before committing Task 2._

- `tests/test_model_score.py` - four new tests under a `CR-01 regression` header: row-id ordering contract, EP backfill-from-next-play, WP backfill-from-next-play, cross-game non-regression.

## Decisions Made
- Fixed the root cause inside `_score_probabilities` (the plan's primary recommendation) rather than sorting at each of `score_plays`' two call sites, so no future caller of `_score_probabilities` can reintroduce the defect.
- Followed the plan's explicit instruction not to assert null-adjacent-row `epa` equality between the mixed frame and a fully-complete frame, since that equality does not hold even with the fix (the preceding row's `home_ep_after` source differs structurally between the two frames). Used the EP/WP backfill-from-next-play form instead, which is the correct discriminating assertion.

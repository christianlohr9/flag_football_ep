flag_football_ep.validation.checks:
  class Status(str, Enum): PASS="pass"; FAIL="fail"; WARN="warn"; SKIPPED="skipped"
  CheckResult: dataclass(game_id: str, check: str, status: Status, detail: str, n_offending: int)
  GameResult:  dataclass(game_id: str, source: str, results: list[CheckResult],
                         quarantined: bool, reasons: list[str])

  CHECKS: dict[str, Callable]   # keys, in report order:
    "downs_range", "yardline_range", "half_assigned", "monotonic_drive_ids",
    "gapless_play_ids", "score_reconstruction"

  run_checks(plays: pl.DataFrame, final_scores: pl.DataFrame | None) -> list[CheckResult]
  partition_games(plays: pl.DataFrame, results: list[CheckResult],
                  warn_only_sources: frozenset[str] = frozenset({"legacy"}))
      -> tuple[pl.DataFrame, pl.DataFrame, list[GameResult]]   # (accepted, quarantined, per-game results)

flag_football_ep.validation.report:
  render_report(game_results: list[GameResult], notices: dict[str, list[str]],
                contract_version: str, run_id: str) -> str
  write_report(markdown: str, out_dir: Path, run_id: str) -> Path   # data/processed/validation-report-<run_id>.md
  console_summary(game_results: list[GameResult]) -> None

    - `downs_range`: PASS when every `down` is 0..4; FAIL naming the offending values and row count when a 7 or a -1 is present; FAIL when `down` is null (null down is unusable, not tolerable)
    - `yardline_range`: PASS when every `yardline_50` is 0..50 inclusive; FAIL with the min/max found otherwise
    - `half_assigned`: PASS when every `half` is 1 or 2; FAIL with detail "no half boundary" when `half` is null; FAIL naming the value when it is 3
    - `monotonic_drive_ids`: PASS when `drive_id` is non-decreasing across ascending `play_id` and starts at 1; FAIL on the sequence 1,2,2,1,3 reporting the first decreasing play_id; FAIL when the first drive_id is not 1
    - `gapless_play_ids`: PASS when `play_id` is exactly 1..N with no duplicates; FAIL naming the missing ids when 14 is skipped; FAIL naming the duplicated id when one repeats
    - `score_reconstruction`: PASS when the last row's `home_team_score`/`away_team_score` equal the reference row for that game_id after aligning by team code; FAIL reporting reconstructed vs reference for both teams when they differ; FAIL when the reference row's home/away teams do not match the frame's home/away teams (convention mismatch); SKIPPED with detail "no reference entry" when the game_id is absent from the reference frame or `final_scores` is None
    - every check returns one `CheckResult` per game_id present in the frame, never a single aggregate result
    - `run_checks` on a frame with two games returns 12 results (6 checks x 2 games) in a deterministic order
    - checks never raise on an empty frame: `run_checks` on zero rows returns an empty list
  </behavior>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| parsed source frames → canonical Parquet | the validation gate is the only thing standing between untrusted exports/API payloads and the analysis dataset |
| validation results → Markdown report artifact | report content is written to disk and read by a human |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-1.2-03 | Tampering | malformed exports and API payloads reaching `plays.parquet` | mitigate | six per-game checks plus `partition_games` quarantine: a new-format game with any FAIL never reaches the canonical table, and the reason is recorded in the report (ASVS V5 input validation for this phase) |
| T-1.2-17 | Denial of Service | pathological check details (dumping thousands of offending values into the report) | mitigate | `detail` strings are bounded to five example values plus a count; no whole rows are rendered |
| T-1.2-18 | Repudiation | silent row loss in the gate making bad data indistinguishable from filtered data | mitigate | `partition_games` asserts accepted + quarantined equals input height and raises `RuntimeError` otherwise; the report states games ingested and quarantined counts |
| T-1.2-05 | Information Disclosure | secrets or absolute paths leaking into the report artifact | mitigate | the renderer writes only game ids, check names, bounded details and relative paths — no environment values, no API keys |
</threat_model>

<objective>
Contain per-file and per-game ingest failures so no realistic data-quality error can remove an entire source from `plays.parquet`.

Purpose: closes the containment half of Critical finding CR-02 (VERIFICATION gap 2). `hudl.derive_identity_columns` uses strict `pl.Int32` casts on exactly the DN/DIST/YARD LN/PLAY # columns `check_column_domains` documents as notice-worthy; `ingest_dir` catches only two of the three documented per-file structural errors; `sportapp.ingest_snapshots` has a strict `yards_to_go` cast inside its per-game loop with no per-game guard. Each of those escapes into `pipeline.py`'s blanket `except Exception`, which drops every game of that source for the run.
Output: non-strict casts, complete per-file/per-game containment, and a null-safe `gapless_play_ids` so the newly-possible null `play_id` is reported rather than crashing the validation gate.

Plan 22 makes the resulting notices operator-visible; this plan makes sure there is something to report instead of a vanished source.
</objective>

| operator-supplied export files → ingest | hand-charted CSV/JSON of arbitrary content crosses into the pipeline; any cell can be malformed |
| per-file failure → per-source result | one file's failure must not be able to change the outcome for the other files of that source |

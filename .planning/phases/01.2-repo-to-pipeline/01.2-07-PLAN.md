<objective>
Implement the network layer: two `ffep fetch-*` subcommands that snapshot raw JSON to disk and stop there.

Purpose: the snapshot-first decision means ingest always reads from disk, so fetch is the only place with network I/O and the only place that touches secrets. Isolating it here makes ingest offline, reproducible and testable, and confines the API-key blast radius to one module.
Output: `fetch/http.py`, `fetch/sportapp.py`, `fetch/ifaf.py`, mocked-HTTP tests, and a live cpx.studio discovery run that answers RESEARCH Open Question 4 (auth, rate limits, real response shape).
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| external APIs → local filesystem | untrusted remote payloads are written to disk here |
| environment secrets → HTTP requests | the sportapp.fi apikey and any cpx token cross into network traffic and log output |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-1.2-04 | Tampering | remote responses (undocumented cpx.studio API, unverified shapes) | mitigate | `http_get_json` enforces a timeout, `raise_for_status`, explicit JSON-decode handling and per-request failure isolation; unknown payload shapes are snapshotted and reported instead of being guessed at |
| T-1.2-05 | Information Disclosure | apikey in URLs, logs and exception text | mitigate | the key travels as a `requests` `params` entry (never string-interpolated into a URL), every message goes through `redact(secret_values=[key])`, and a sentinel-key test asserts absence from artifacts and stdout |
| T-1.2-19 | Tampering | attacker-controlled or typo'd base URL redirecting fetch to another host | mitigate | URLs are always `base_url` + a fixed path from config; callers cannot pass full URLs; `base_url` values are https in the checked-in `ffep.toml` |
| T-1.2-20 | Denial of Service | unbounded events pagination against a misbehaving endpoint | mitigate | page loop hard-stops at 50 pages with a warning; every request has a 30 s timeout |
| T-1.2-21 | Tampering | interrupted download leaving a truncated JSON snapshot that ingest later trusts | mitigate | atomic `.tmp` + `os.replace` writes; a failed request writes nothing |
</threat_model>

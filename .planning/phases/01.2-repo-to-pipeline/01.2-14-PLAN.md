Create `src/flag_football_ep/pipeline.py` with `IngestResult` and `run_ingest` per the `<interfaces>` block.

Order of operations:
1. Generate `run_id` as `datetime.now().strftime("%Y%m%d-%H%M%S")` once.
2. Load the contract and all reference frames once.
3. For each requested source in a fixed order (hudl, legacy, sportapp, ifaf), dispatch to its ingest entry point inside a try/except that records the failure and continues. Collect per-game frames plus their `IngestNotices`.
4. Concatenate the per-game frames with `pl.concat(..., how="vertical")` — every frame is already conformed, so a schema mismatch here is a bug and must raise rather than fall back to `diagonal`.
5. `run_checks` on the combined frame with the loaded final scores, then `partition_games` with the warn-only source set.
6. Return `IngestResult` (the writes land in task 2).

Rules:
- Validate the `sources` argument against the four known names before doing any work.
- Never swallow an exception silently: every caught error appends a notice carrying the source, the game or file and the exception class plus message.
- `strict` only affects the caller's exit code path, never what gets written.

## Trust Boundaries

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-1.2-06 | Tampering | non-atomic Parquet rebuild leaving a corrupt or partial canonical dataset | mitigate | `_atomic_write_parquet` writes a `.tmp` sibling then `os.replace`, cleans up on failure, and a test proves a mid-write failure leaves the previous Parquet intact |
| T-1.2-03 | Tampering | invalid games reaching the analysis dataset | mitigate | `partition_games` runs before any write; quarantined rows go only into the report and the games table, never into `plays.parquet` |
| T-1.2-18 | Repudiation | silent per-source failures making a short corpus look normal | mitigate | every caught exception becomes a notice with source, file and exception text; the report states games ingested, quarantined and warned; `--strict` turns quarantine into a non-zero exit |
| T-1.2-05 | Information Disclosure | secrets or absolute paths leaking into report artifacts | mitigate | the pipeline passes only game ids, counts and relative paths to the renderer; no environment values are logged |
| T-1.2-30 | Tampering | schema drift between sources being papered over by a diagonal concat | mitigate | vertical concat only, asserted by a grep gate — a schema mismatch raises instead of silently producing null columns |
</threat_model>

<objective>
Build the metrics module that HC-04 turns on: one new pure-function module over canonical plays
that computes, on the same rows, (a) the head coach's `Explosive %` exactly as his workbook
implements it, (b) the rule he described verbally, (c) success rate as `epa > 0`, (d) an
IsoPPP-style explosiveness rate over successful plays with a threshold calibrated from our corpus
and stored as a versioned artifact, and (e) a continuous per-play score that has no cliff at all.

The hard part is discipline, not maths. The workbook formula and the verbal description disagree
(RESEARCH Pitfall 1); the workbook's `Efficiency` column is manually charted and could not be
re-derived (RESEARCH Pitfall 2); the workbook's denominator is pass-only (Pitfall 3); PAT rows
would silently deflate every rate (Pitfall 5). Each of those must survive into the code as a named,
tested behaviour rather than being smoothed over.

Purpose: everything M3-03-02 does (run on the real corpus, write the German proposal, ask the head
coach three questions) is a thin layer over this module. If the baseline here is a re-interpretation
rather than a reproduction, the whole comparison is worthless.
Output: `src/flag_football_ep/features/explosiveness.py` and
`tests/test_features_explosiveness.py`, both built on synthetic frames only.
</objective>

Verified play-type facts (read directly from `src/flag_football_ep/ingest/hudl.py`, do not
re-derive): a sack maps to `play_type == "pass"`; a `Dropped` / `Batted Down` / `Block` RESULT
token also maps to `play_type == "pass"` and sets `incomplete_pass`. So the workbook's
`Attempts = Comps + Incs + Sacks` corresponds to `play_type == "pass"` in canonical terms.
Whether the workbook's `Incs` already contains its `Drops` is unknown — that ambiguity is HC
question 5 in M3-03-02 and must be represented in the code as an explicit optional argument, never
as a chosen answer.

Pinned head-coach workbook formulas (source: `docs/explosiveness-recherche.md`, itself read from
the formula cells with `openpyxl(data_only=False)`; cite that document in the module docstring):

```
Player Analysis All Camps!R2/S2:
  ExpPlays   = COUNTIFS(Data!P, <QB>, Data!J, ">12")     ' J = GN/LS, P = Thrown By
  Explosive% = ExpPlays / Attempts                        ' Attempts = Comps+Incs+Sacks (pass only)
Player Analysis All Camps!U2:
  Efficiency = SUMIF(Data!P, <QB>, Data!O) / (Attempts + Drops)   ' O = charted 0/1 Efficiency
```

Corpus numbers this module's defaults are calibrated against (RESEARCH § "Unsere eigene
Yards-Verteilung", n = 15,006 scrimmage plays / 14,669 with EPA). They are expectations for the
M3-03-02 run, NOT constants to hard-code:

```
share yards_gained > 12          16.7 %
success rate (epa > 0)           52.2 %
verbal rule (>12 OR epa>0)       52.8 %   (only 89 plays, 0.6 %, added by the yards clause)
q80 of epa among successes       ~ +2.3
median / mean epa on successes   +1.14 / +1.60
cliff zone 10-12 yards           11.5 % of all plays
```

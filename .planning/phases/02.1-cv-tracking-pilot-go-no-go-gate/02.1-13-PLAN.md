<objective>
Convert pixel tracks into field coordinates: a human picks the 4-8 landmark correspondences per hover
position, the transform is applied to every track's ground-contact point, and the held-out landmarks
give a measured reprojection error in yards.

Purpose: ROADMAP success criterion 3 and half of C-09's position-error criterion. D-13 fixes yards on
the `yardline_50` axis as the output unit so Phase 2.3's EPA join reads native coaching units, and
D-10 asks for landmark reprojection as an independent check on homography quality.
Output: filled calibration CSV, `cv/coordinates.py`, `{session}_xy.parquet`,
`docs/homography-calibration.md`.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| hand-picked calibration coordinates -> every downstream field coordinate | one mis-picked landmark biases the whole XY dataset |
| calibration reference frames -> git | annotated frames show identifiable players |
| XY Parquet -> Phase 2.3 | this artifact is the contract every later coaching metric is computed on |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-2.1-02 | Tampering | operator-entered calibration coordinates | mitigate | `load_calibration` (plan 02.1-04) validates vocabulary, field-table agreement, frame bounds, point count and collinearity; Task 3 additionally reports the out-of-bounds transformed share as a notice |
| T-2.1-33 | Repudiation | an unverifiable homography-quality claim | mitigate | Task 2 requires >= 2 held-out landmarks per position; Task 3 reports their reprojection error in yards and metres and states explicitly that it is not the end-to-end position error |
| T-2.1-34 | Tampering | silently null field coordinates for an uncalibrated hover position | mitigate | Task 3 raises `CalibrationError` naming the position instead of writing nulls, so a missing calibration cannot masquerade as an empty region of the field |
| T-2.1-01 | Information disclosure | `data/labels/calibration/*_ref.jpg` | mitigate | Written under `data/labels/`, gitignored by plan 02.1-01; acceptance criterion asserts `git check-ignore` |
</threat_model>

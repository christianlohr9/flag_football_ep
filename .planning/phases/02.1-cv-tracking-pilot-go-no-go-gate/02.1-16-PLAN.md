  <action>
Implement `render_radar_frame(tracks_at_frame, config, size_wh)` as a pure function returning an
annotated numpy array: draw the pitch from `config.cv.field_length_yards` (50), `field_width_yards`
(25) and `endzone_yards` (10) — both goal lines, the sidelines, the end-zone back lines, and yard
lines every 5 yards with their numbers — then plot each row as a dot at its `(x_yards, y_yards)`
position with the same team colour scheme `overlay.draw_frame` uses, the `track_id` next to it, and a
distinct marker for referees and for null-`team_id` tracks. Map yards to pixels with a single scale
factor so the pitch is never distorted, and orient the view so the west goal line is on the left,
matching the coordinate convention (D-13). Rows with null `x_yards` are skipped, and their count is
reported by the caller — a silently thinner radar would misrepresent the tracking.

Implement `render_showcase_reel(config, clip_numbers, tracks, out_path)`: for each requested clip,
compose per frame a side-by-side canvas with `overlay.draw_frame`'s annotated video frame on the left
and `render_radar_frame` for the same `frame_index` on the right, both scaled to a common height, with
a header strip carrying the clip number, the play index within the reel and a one-line caption. Write
one continuous mp4 at the source fps with a short black separator between plays, and return the path.
Output goes under `config.paths.labels / session_id / "showcase"` — it contains rendered player
footage and is therefore PII, so it stays in the gitignored label tree even though it is a demo asset.

Raise a named exception when a requested clip has no rows with field coordinates, naming the clip —
producing a reel with an empty radar half would misrepresent the pipeline to exactly the audience that
cannot tell the difference.

tests/test_cv_radar.py, array-level, with `synthetic_tracks(with_field_coords=True, with_teams=True)`:
- `render_radar_frame` returns the requested `size_wh` shape, and a player at `(0, 0)` yards lands at
  the expected pixel near the west goal line / south sideline corner (assert the drawn dot's position)
- the pitch aspect ratio is preserved (assert the scale factor is identical on both axes)
- two team ids produce two colours; referee and null-team rows produce their own markers
- rows with null `x_yards` are skipped without raising
- `render_showcase_reel` writes a file whose frame count equals the sum of the requested clips' frames
  plus the separators, and whose width is the sum of the two halves
- a clip with no field-coordinate rows raises the named exception naming the clip
  </action>

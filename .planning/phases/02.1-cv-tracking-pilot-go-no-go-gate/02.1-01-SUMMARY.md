## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] `autodistill.detection.CaptionOntology` unimportable — undeclared `roboflow` dependency**
- **Found during:** Task 3 install probe
- **Issue:** `autodistill` 0.1.29's `detection_base_model.py` imports `roboflow` at module level, but `roboflow` is absent from autodistill's own PyPI `requires_dist` metadata — `from autodistill.detection import CaptionOntology` raises `ModuleNotFoundError: No module named 'roboflow'` on a fresh `uv sync --extra cv`
- **Fix:** Removed `autodistill`/`autodistill-grounding-dino` from the `cv` group (this is the plan's own pre-authorized fallback path for this exact scenario); wired `transformers.GroundingDinoForObjectDetection` with `IDEA-Research/grounding-dino-tiny` as the zero-shot pre-labeling backend instead, verified importable
- **Files modified:** `pyproject.toml`, `docs/cv-setup.md`
- **Verification:** `uv run --extra cv python -c "from transformers import GroundingDinoForObjectDetection"` exits 0
- **Committed in:** `9624e31` (group definition), `6163e3c` (decision record)

**2. [Rule 3 - Blocking] `setuptools` dropped `pkg_resources`, breaking core `hyperopt` import**
- **Found during:** Task 1, first `uv lock` after adding the `cv` group
- **Issue:** The `cv` group's `torch` dependency has no `setuptools` upper bound; uv's single unified lock resolution bumped the whole project's `setuptools` from `73.0.1` to `84.0.0`, a release that no longer ships `pkg_resources` — `hyperopt` (core dependency, imported by `model/hyperparams.py`) fails at load time with `ModuleNotFoundError: No module named 'pkg_resources'` even in a plain `uv sync` with no `--extra cv`
- **Fix:** Added `setuptools>=73.0.1,<81` to core `[project.dependencies]`
- **Files modified:** `pyproject.toml`, `uv.lock`
- **Verification:** `uv run python -c "import pkg_resources"` succeeds (with the expected upstream deprecation warning)
- **Committed in:** `9624e31`

**3. [Rule 1 - Bug] `xgboost` 2.1.1 incompatible with `scikit-learn>=1.6` forced by the `cv` group**
- **Found during:** Task 2 verification (`uv run pytest` across every test file touching `Config`)
- **Issue:** `umap-learn>=0.5.12` (required by the `cv` group) itself requires `scikit-learn>=1.6`. Under uv's unified single-resolution lock, this bumps core `scikit-learn` from whatever the pre-Phase-2.1 environment had to `1.9.0`. Scikit-learn 1.6 removed the plain `_estimator_type` class attribute `RegressorMixin`/`ClassifierMixin` used to set; `xgboost==2.1.1`'s sklearn wrapper still reads `self._estimator_type` directly inside `save_model()`, so every `mlflow.xgboost.log_model()` call (the entire EP/WP training and scoring test suite) raised `TypeError: _estimator_type undefined`
- **Fix:** Raised the `xgboost` floor to `>=2.1.4` (resolved to `3.4.1`), a release line with `__sklearn_tags__` support that no longer depends on the removed attribute. Capping `scikit-learn` back below 1.6 was rejected — it would conflict with the `cv` group's own `umap-learn` requirement
- **Files modified:** `pyproject.toml`, `uv.lock`
- **Verification:** `uv run pytest -q` (full suite, core environment) exits 0; `mlflow.xgboost.log_model` round-trips cleanly in `tests/test_model_registry.py`/`test_model_score.py`/`test_model_train.py`
- **Committed in:** `2339410`

**4. [Rule 3 - Blocking] Companion test fixtures missing the new required `Config` fields**
- **Found during:** Task 2 verification
- **Issue:** Extending `Paths`/`ReferenceFiles`/`Config` with new required (no-default) fields broke every test file that constructs these dataclasses directly or hand-writes `ffep.toml` text: `tests/test_config.py` (`MINIMAL_TOML`), `tests/test_model_evaluate.py`, `tests/test_model_experiments.py`, `tests/test_model_registry.py`, `tests/test_model_score.py`, `tests/test_model_train.py`, `tests/test_pipeline_ingest.py` (`_make_config`/`_write_toml_config`), `tests/test_reports_own_team.py`, and `tests/test_cli_report.py` (`_config_to_toml`, which serializes an arbitrary `Config` back to TOML and is reused by `test_cli_run.py`/`test_cli_smoke.py`)
- **Fix:** Extended every `_make_config`-style helper with `video`/`labels`/`tracking` paths, the four new reference-file paths, and a `CvSettings` instance; extended every raw-TOML-writing helper with the matching keys and a `[cv]` table
- **Files modified:** `tests/test_config.py`, `tests/test_model_evaluate.py`, `tests/test_model_experiments.py`, `tests/test_model_registry.py`, `tests/test_model_score.py`, `tests/test_model_train.py`, `tests/test_pipeline_ingest.py`, `tests/test_reports_own_team.py`, `tests/test_cli_report.py`
- **Verification:** `uv run pytest -q` (full suite) exits 0
- **Committed in:** `2339410`

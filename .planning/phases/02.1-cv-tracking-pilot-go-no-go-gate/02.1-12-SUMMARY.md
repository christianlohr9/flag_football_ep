## Accomplishments

- `cv.track.track_session(config, session_id, *, run_id=None, resolution=None, sahi=None, out_path=None)`: loads the champion detector once, iterates `frames.clip_paths` in clip-number order, gives every clip its own `trackers.OCSORTTracker` instance (track ids per-clip, D-02), drops OC-SORT's `-1` "not yet confirmed" sentinel rows, writes `foot_x_px`/`foot_y_px` as the bbox bottom-centre, and wraps every clip in its own `try`/`except` (mirroring `pipeline.run_ingest`'s per-source containment) appending a notice naming the clip for a raise, a zero-track outcome, or a decoded-frame-count mismatch against `video_inventory.csv`'s declared duration (>2 frames). Accumulates `decode`/`detect`/`track`/`write` stage seconds and writes through `schema.write_tracking_parquet`.
- `cv.teams.assign_teams(tracks, config, *, crops_by_track)`: fits one `TeamClassifier` per session (never per clip -- KMeans labels are arbitrary per fit), sampling crops in a fixed sorted-key order across every non-referee track (capped at `_MAX_FIT_CROPS_PER_TRACK`) so the fit never depends on caller iteration order; assigns `team_id` per track by majority vote over that track's own predicted crops, leaving it null plus a notice naming the track when the majority share is below 0.6; referee rows/crops are excluded from both the fit and prediction entirely. Returns a new `TeamAssignmentResult(tracks, notices)`.
- Ran the real pipeline over all 61 registered pilot clips (chunked across 4 process invocations by cumulative clip duration to respect the 10-minute per-command execution limit; `track_session` itself ran completely unmodified against each clip subset via a process-local `frames.clip_paths` monkeypatch in a throwaway driver script, never touching the repo): 61/61 clips processed, **zero notices**, **zero zero-track clips**, 2031 distinct tracks (1874 `player`, 157 `referee`).
- Real C-09 extrapolation from the full 61-clip stage timings (`decode=29.21s`, `detect=473.00s`, `track=11.03s`, `write=0.09s` over 664.41s of footage): **38.63 min for a 50-minute game**, comfortably inside the 60-minute budget and consistent with plan 02.1-11's three-clip estimate (39.73 min) -- this is now the real gate number, not a sample.
- Ran `assign_teams` for real: extracted up to 10 crops per track from the decoded clips, embedded all 17,626 crops through the real SigLIP model (`google/siglip-base-patch16-224`), fit one session-wide `TeamClassifier`, and wrote the final tracking Parquet with `team_id` filled. **1864/1874 (99.47%) of player tracks got a team assignment**; 10 tracks landed exactly on a 0.50 majority split and stayed null (listed verbatim in `docs/cv-setup.md`).
- `docs/cv-setup.md`'s new `## Tracking-Lauf` section (German) records date, machine, detector run id, resolved settings, the chunked-execution methodology, per-stage seconds, the full extrapolation formula, clip/track counts, the team-assignment share, the output Parquet path/row count, and every notice (zero from tracking; the 10 ambiguous-track notices from team assignment in their own subsection).

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] `TeamClassifier._ensure_siglip` used the wrong processor class, breaking every real (non-test) SigLIP call**
- **Found during:** Task 3, while running the real 61-clip team-assignment measurement
- **Issue:** `AutoProcessor.from_pretrained("google/siglip-base-patch16-224")` unconditionally also tries to resolve the paired `SiglipTokenizer` (the text side), even though `TeamClassifier` only ever needs the image side. That raises `ImportError: ... requires the SentencePiece library` on this project's environment, which never installed `sentencepiece` (nothing here does text encoding). Not caught by any existing test because every offline test injects a fake `embedder`, so the real SigLIP path had never actually been exercised since plan 02.1-06 wrote it.
- **Fix:** `SiglipImageProcessor.from_pretrained(...)` directly -- loads only the vision preprocessing config, matching what `SiglipVisionModel` consumes, no tokenizer/SentencePiece dependency at all.
- **Files modified:** `src/flag_football_ep/cv/teams.py`
- **Verification:** `tests/test_cv_teams.py` (offline, unaffected) stayed green; the real fix was verified by the Task 3 run itself succeeding end-to-end against real SigLIP weights over 17,626 real crops.
- **Commit:** `fe1042d` (bundled with the Task 3 docs commit, since it was discovered while producing that task's real measurement)

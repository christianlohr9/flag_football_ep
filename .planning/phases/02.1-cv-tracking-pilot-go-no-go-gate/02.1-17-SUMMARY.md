## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Fixed section-extraction bug in the structural test's own helper logic**
- **Found during:** Task 3, first run of `tests/test_cv_gate_artifacts.py`
- **Issue:** `text.split("## Gate-Kriterien und Messung", 1)[1].split("##", 1)[0]` truncated the criteria section mid-row, because criterion 2's cell cites `` `### Gemessener Positionsfehler (v2)` `` — a `###` sub-heading whose leading `##` substring matched the naive second split, cutting the section short and losing rows 2 and 3.
- **Fix:** replaced with a `_section()` helper that finds the next **line-anchored** `^## ` heading via regex (`re.MULTILINE`), which never matches a `###`/`####` sub-heading embedded inside a table cell or citation.
- **Files modified:** `tests/test_cv_gate_artifacts.py`
- **Verification:** `uv run --extra cv pytest tests/test_cv_gate_artifacts.py -q` — 9/9 passed after the fix (was failing 1/9 before, with the criteria-table-row-count test reporting only 1 of 3 rows found)
- **Committed in:** `d32508b` (part of the Task 3 commit — the bug was caught and fixed before the file was ever committed, so no separate fix commit exists)

### Documented Plan Overrides (pre-authorized by the orchestrator, not autonomous deviations)

**2. Continuity criterion 1 uses the upper-bound argument instead of the plan's literal "stop when `pass_rate` is `None`" instruction**
- **Context:** the plan's Task 1 action text says "If `summarise_review` returns `pass_rate is None`, stop and report the unreviewed clips — the gate cannot be drafted from a partial review." The real, committed `data/reference/continuity_review.csv` has only 20/61 clips reviewed (`pass_rate: None` by design), per plan 02.1-14's documented, human-approved decision to stop once the ≥90% target became mathematically unreachable.
- **Handling:** per explicit orchestrator instruction (relayed at spawn time as `<gate_facts>`), this specific, already-documented case overrides the literal stop instruction: the upper-bound argument (all 41 unreviewed clips counted as pass, the one direction of bias safe to apply without reviewing further) is used instead, and it alone proves the criterion missed (47/61 = 77.0% < 90%). This is not a new autonomous decision — it was pre-authorized before Task 1 began, with the rationale and prior evidence (02.1-14-SUMMARY.md, commit `755b156`) already on record.
- **Files affected:** `docs/pilot-gate-decision.md`, `tests/test_cv_gate_artifacts.py`
- **Verification:** `summarise_review()` re-run live confirms `n_clips=61, n_pass=6, n_reviewed=20, pass_rate=None`; the recomputed upper bound `(6+41)/61 = 0.7705 < 0.90` is asserted directly in the structural test rather than merely stated in prose.

**3. Plan's literal Task 1/Task 2 `<verify>` commands (`assert s['pass_rate'] is not None`) do not pass against the real data, by design**
- **Context:** both Task 1's and Task 2's `<verify>` blocks in the plan assert `pass_rate is not None`, which is the exact condition Deviation #2 above establishes does not hold for this session's real evidence.
- **Handling:** ran the amended verification specified in the spawn-time `<gate_facts>` instead — confirming `n_clips == 61`, `docs/pilot-accuracy.md` exists, and the extrapolation formula is present in the draft — which is the evidence-completeness bar that actually applies to the sanctioned partial-review case. This is documented here rather than silently swapped in, since it is a literal deviation from the plan's printed `<verify>` command text (though not from its underlying intent, which the orchestrator's override instructions supersede).
- **Verification:** amended verification command run and its output recorded in the Task 1 checkpoint return and in this summary.

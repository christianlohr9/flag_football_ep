# Phase 02.1 — Validation Strategy

> Per-phase validation contract for feedback sampling during execution.

---

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | pytest >= 8 (already a project dev-dependency, `[dependency-groups] dev`) |
| **Config file** | `pyproject.toml` `[tool.pytest.ini_options]` (`testpaths = ["tests"]`, `addopts = "-q"`) |
| **Quick run command** | `uv run --extra cv pytest tests/test_cv_*.py -q` (waves 1–2, before the `cv` extra is installed: `uv run pytest tests/test_cv_*.py -q`) |
| **Full suite command** | `uv run --extra cv pytest -q` |
| **Estimated runtime** | ~30 s quick, ~90 s full |

No CV test may download model weights or read real footage. Every CV test runs against the synthetic
factories in `src/flag_football_ep/testing.py` and small fixtures under `tests/fixtures/cv/`, per the
existing `testing.py` factory convention (02.1-RESEARCH.md § Validation Architecture).

---

## Sampling Rate

- **After every task commit:** `uv run --extra cv pytest tests/test_cv_*.py -q`
- **After every plan wave:** `uv run --extra cv pytest -q`
- **Before `/gsd:verify-work`:** full suite green **plus** the manual C-09 gate review (D-09 / D-10 /
  D-11) recorded in `docs/pilot-gate-decision.md`. The automated suite cannot substitute for the human
  track-overlay review or the ground-truth position-error measurement — those are the phase deliverable.
- **Max feedback latency:** 120 s

## Manual-Only Verifications

The three C-09 gate criteria (>= 90% track continuity, ~<= 1 m position error, < 1 h/game inference)
are the phase's deliverable, not something a unit test asserts. Each manual step below is nonetheless
followed by an automated gate that reads back the state the human produced, so the human step cannot
be silently skipped.

| Behavior | Requirement | Why Manual | Test Instructions |
|----------|-------------|------------|-------------------|
| Sighting review: hover grouping is real and the inference settings are locked (02.1-03-03) | REQ-S2-02 | Requires a human to look at contact sheets and judge whether clips share a hover position | Open the sighting contact sheets, confirm the 61 clips group as reported, set `cv.resolution`/`cv.sahi` in `ffep.toml`, then run the 02.1-03-03 gate command |
| CVAT correction of the pre-labelled frames (02.1-09-02) | REQ-S2-02 | Box correction is human annotation work; no API substitutes for judging a box | Correct the pre-labels in the local CVAT task, stay under the D-06 ceiling of 600 images, then `ffep cv cvat-pull` and let 02.1-09-01's validation gate the result |
| RF-DETR fine-tune on the CUDA box (02.1-10-02) | REQ-S2-02 | Training runs on a second physical machine that Claude cannot reach | Run the training command on the CUDA box, verify the dataset hash in `params.json`, copy the artifacts back, then run the 02.1-10-02 artifact gate |
| Homography point picking per hover position (02.1-13-02) | REQ-S2-02 | Field landmarks must be identified by eye in each reference frame | Pick >= 4 fit points and >= 2 held-out landmarks per hover position, then run the 02.1-13-02 gate; `load_calibration` rejects malformed input |
| 61-clip track-continuity review (02.1-14-03) | REQ-S2-02 (C-09 criterion 1) | "Tracked without an ID switch" is a visual judgement over a whole play (D-09) | Watch every overlay video, record `verdict`/`id_switches`/`reviewer_note` per clip in `data/reference/continuity_review.csv`, then run the 02.1-14-03 gate — `pass_rate` stays `None` while any clip is unreviewed |
| Ground-truth foot-position labelling (02.1-15-02) | REQ-S2-02 (C-09 criterion 2) | The position-error target is unfalsifiable without hand-labelled ground truth (D-10) | Mark >= 200 foot positions across all 5 field zones and >= 5 known-distance scale pairs, then run the 02.1-15-02 gate |
| Go/no-go verdict (02.1-17-02) | REQ-S2-02 | The phase deliverable is a human decision against the measured numbers (D-12) | Read the criteria table in `docs/pilot-gate-decision.md`, choose GO / NO-GO / TEILWEISE, record it with its consequence per D-06, then run the 02.1-17-02 evidence gate |

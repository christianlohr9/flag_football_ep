### `src/flag_football_ep/cv/track.py` (service, streaming per-clip loop)

**Analog:** `src/flag_football_ep/pipeline.py` (`run_ingest`, module docstring lines 1-32 + `_atomic_write_parquet` lines 114-126)

**Per-item try/except so one bad clip never aborts the run** (docstring lines 6-8, mirrored in code): `run_ingest` dispatches each source through its own `ingest/*` entry point "inside a per-source try/except (so one broken source never aborts the run)". `cv/track.py` should apply the identical discipline per-clip: one clip's tracking failure (e.g. zero detections, a corrupt frame) is caught, logged as a notice, and the loop continues across all 61 clips — this is what makes the D-09 "whole game is the denominator" gate measurement possible without a single bad clip blocking the run.

**Atomic Parquet write** (pipeline.py lines 114-126):
```python
def _atomic_write_parquet(df: pl.DataFrame, path: Path) -> None:
    path.parent.mkdir(parents=True, exist_ok=True)
    tmp_path = path.with_suffix(path.suffix + ".tmp")
    try:
        df.write_parquet(tmp_path)
        os.replace(tmp_path, path)
    finally:
        tmp_path.unlink(missing_ok=True)
```
Copy this helper verbatim (or import it if made shared) for `data/processed/tracking/*.parquet` — D-14 explicitly calls for "same pattern and dtype-safety discipline as `plays.parquet`".

**Notices-collection convention** (pipeline.py docstring lines 26-30): collect a `notices: list[str]` alongside the tracked-output dataclass, echoed via `typer.echo(f"notice: {n}")` in the CLI command — reuse for per-clip tracking anomalies (e.g. "clip 037: 0 detections after frame 210").

**Homography math itself — copy from RESEARCH.md verbatim** (not from this repo, no analog exists):
```python
class ViewTransformer:
    def __init__(self, source: np.ndarray, target: np.ndarray):
        source = source.astype(np.float32)
        target = target.astype(np.float32)
        self.m, _ = cv2.findHomography(source, target)
        if self.m is None:
            raise ValueError("homography could not be calculated")

    def transform_points(self, points: np.ndarray) -> np.ndarray:
        if points.size == 0:
            return points
        reshaped = points.reshape(-1, 1, 2).astype(np.float32)
        transformed = cv2.perspectiveTransform(reshaped, self.m)
        return transformed.reshape(-1, 2)

    def transform_image(self, image: np.ndarray, resolution_wh: tuple) -> np.ndarray:
        return cv2.warpPerspective(image, self.m, resolution_wh)
```
(Source: `github.com/roboflow/sports` `sports/common/view.py`, MIT — verified in RESEARCH.md Pattern 3.) Target array values are yards directly (D-13), so no unit-conversion step downstream.

### `src/flag_football_ep/cv/teams.py` (service, transform)

**Analog for structure:** `src/flag_football_ep/features/mutations.py` (pure-function-over-a-frame convention — not read in full this session, but its role/shape is well-established across the codebase: stateless transforms taking/returning `pl.DataFrame`)

**Core algorithm — copy from RESEARCH.md Pattern 2 verbatim** (no in-repo analog; SigLIP+UMAP+KMeans is new to this codebase):
```python
from transformers import SiglipVisionModel, AutoProcessor
import umap
from sklearn.cluster import KMeans

SIGLIP_MODEL_PATH = "google/siglip-base-patch16-224"

class TeamClassifier:
    def __init__(self, device="cpu"):
        self.model = SiglipVisionModel.from_pretrained(SIGLIP_MODEL_PATH).to(device)
        self.processor = AutoProcessor.from_pretrained(SIGLIP_MODEL_PATH)
        self.reducer = umap.UMAP(n_components=3)
        self.cluster_model = KMeans(n_clusters=2)

    def fit(self, crops):
        features = self.extract_features(crops)
        projections = self.reducer.fit_transform(features)
        self.cluster_model.fit(projections)

    def predict(self, crops):
        features = self.extract_features(crops)
        projections = self.reducer.transform(features)
        return self.cluster_model.predict(projections)
```

### MLflow store routing (never call `mlflow.set_tracking_uri` with a raw `file:` path)

```python
def ensure_experiment(name: str, config: Config) -> str:
```

```python
def _atomic_write_parquet(df: pl.DataFrame, path: Path) -> None:
    path.parent.mkdir(parents=True, exist_ok=True)
    tmp_path = path.with_suffix(path.suffix + ".tmp")
    try:
        df.write_parquet(tmp_path)
        os.replace(tmp_path, path)
    finally:
        tmp_path.unlink(missing_ok=True)
```

```python
def _read_reference_csv(path: Path, schema: dict[str, pl.DataType]) -> pl.DataFrame:
    if not path.exists():
```

   the GT point count and match rate, basis `docs/pilot-accuracy.md`

   `docs/cv-setup.md` §Tracking-Lauf

agreement, the homography-versus-pipeline error split, and the reprojection error per hover position.

`## Entscheidung` — an empty verdict block for Task 2.

`## Konsequenzen` — spelled out in advance, so the verdict cannot be softened after the fact:
GO -> Phase 2.2 (dataset buildout) and 2.3 (coaching metrics) unblock; NO-GO -> back to Phase 2.0
capture setup per D-06 (a clear miss is answered with better capture, never with more training labels);

citing the per-zone and per-clip evidence.

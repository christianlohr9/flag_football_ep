### Auto-fixed Issues

**1. [Rule 3 - Blocking] `ffep cv dataset` had no way to override `validate_coco`'s image-count band**
- **Found during:** Task 2, attempting the plan's own acceptance-criteria command against the 739-image merged directory
- **Issue:** `validate_coco(coco_dir, manifest, *, min_images=None, max_images=None)` (frozen contract, plan 02.2-09) already supports an explicit multi-domain band, but `cv/commands.py`'s `dataset` typer command always called it with no override — silently defaulting to the Phase-2.1 single-domain `[250, 600]` band. - **Fix:** Added `--min-images`/`--max-images` typer options (default `None`, forwarded straight through to `validate_coco`), preserving every existing call site's behavior exactly.
- **Files modified:** `src/flag_football_ep/cv/commands.py`
- **Verification:** `ffep cv dataset --help` shows both options; real invocation with `--min-images 1 --max-images 3000` against the merged dataset exits 0 and prints the stats table; `uv run pytest tests/test_cv_dataset.py -x -q` (25 passed, unaffected)
- **Committed in:** `640b7dd` (Task 2 commit)

**2. [Rule 3 - Blocking] `dvc add` refused to write the pointer file because `.gitignore` also matched it**
- **Found during:** Task 3, first `dvc add data/labels/dataset` attempt

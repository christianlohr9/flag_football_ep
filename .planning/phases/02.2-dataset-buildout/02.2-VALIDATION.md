## Wave 0 Requirements

Existing infrastructure covers the framework (pytest + `flag_football_ep.testing` frame factories +
the schema-gate style of `tests/test_capture_artifacts.py` and `tests/test_cv_dependencies.py`).
New test modules are created inside the plan that introduces the behaviour they cover, so no
separate Wave 0 plan is required:

- `tests/test_phase22_docs.py` — plan 02.2-01 (extended by 02.2-06, 02.2-11, 02.2-19)
- `tests/test_cv_benchmark_labels.py` — plan 02.2-03
- `tests/test_dvc_layout.py` — plan 02.2-04
- `tests/test_cv_freeze.py` — plan 02.2-07
- `tests/test_cv_active_learning.py` — plan 02.2-09
- `tests/test_cv_bundle.py`, `tests/test_hackathon_scoring.py` — plan 02.2-10

One dependency ordering matters: `tests/test_cv_contracts.py` is extended in plan 02.2-05 (wave 2)
and every later plan implements behind those frozen signatures, so a signature drift fails before
the implementing plan's own tests run.

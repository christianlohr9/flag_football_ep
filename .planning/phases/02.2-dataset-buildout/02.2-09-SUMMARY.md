# Phase 02.2 Plan 09: Active Learning, Finetuned Prelabel Backend & Multi-Domain Dataset Validation Summary

**Implemented `cv/active_learning.py`'s uncertainty+diversity frame selection (candidate pool restricted to `role=pool` clips, coarse grid over `detect.detect_video`'s existing decode+detect batching, seeded reproducible tie-breaking), `cv/prelabel.py`'s fine-tuned-detector prelabel backend (always resolves the rolling `champion` alias, never the freeze pin), and `cv/dataset.py`'s multi-domain-aware `validate_coco` (parameterised `[min_images, max_images]` band plus a per-domain player-box collapse check) — the three genuinely new pieces of behaviour the active-learning loop needed before the first labelling weekend.**

## Accomplishments

- `frame_uncertainty_score`: 1.0 for an empty detection set, a strictly-lower value in `[0, 1)` that decreases as confidence moves away from `_MODEL_CONFIDENCE_THRESHOLD` (0.5) for a non-empty frame
- `diversity_key`: `(domain, session_id, stratum_id, field_zone_bucket)` extracted from any attribute- or dict-shaped row
- `select_al_frames`: builds each session's candidate pool from `clip_paths` minus `frames.read_eval_split`'s `role=frozen_eval` clips (T-2.2-25), scores a coarse per-clip grid of `detect_video`'s decoded frames, groups by `diversity_key`, allocates `target` proportionally via `frames._allocate_proportional` with a floor of 1 per non-empty group, breaks uncertainty ties with a `seed`-derived shuffle, extracts selected frames via `frames.extract_frames`, and persists an `ALSelection` manifest; `iteration > 1` excludes every frame already present in `iteration - 1`'s manifest
- `write_selection_manifest`/`read_selection_manifest`: atomic `.tmp` + `os.replace` JSON round trip, mirroring `frames.py::write_manifest`/`read_manifest`
- `_load_finetuned_backend`: resolves `run_id` through `detect.load_detector`'s own default (explicit argument, else `champion`), reuses `detect._detect_full_frame`'s confidence filter and `detect._to_detection_batch`'s class validation, raises `PrelabelBackendUnavailable` (not a bare `WeightsNotFound`) naming the resolution failure
- `validate_coco(coco_dir, manifest, *, min_images=None, max_images=None)`: defaults resolve `_MIN_IMAGES`/`_MAX_IMAGES` at call time (preserving `monkeypatch.setattr(dataset, "_MIN_IMAGES", ...)`); new `_MIN_IMAGES_MULTIDOMAIN = 1500`/`_MAX_IMAGES_MULTIDOMAIN = 3000`; a domain contributing zero `player` boxes raises `DatasetError` naming it; `DatasetStats.boxes_by_domain` reuses the existing per-class + `"_empty_images"` shape, one entry per domain
- `FrameSample.domain` (new field, default `"drone"`, populated by `sample_training_frames`) — the carrier `validate_coco` needs since it has no `config` parameter to resolve domain any other way
- 14 new tests in `tests/test_cv_active_learning.py` (pure-function coverage, manifest round trip, frozen-eval exclusion via an undecodable placeholder clip, diversity-vs-naive-flat-ranking comparison, stratum share/floor, iteration exclusion, seed determinism, extraction/persistence), 5 new tests in `tests/test_cv_prelabel.py` (finetuned-backend category mapping, confidence filtering, unavailable-backend wrapping, backend-order exclusion, docstring), 5 new tests in `tests/test_cv_dataset.py` (two-domain pass, domain-collapse-raises-named-domain, band-parameterisation accept/reject, pilot single-domain unchanged, `_MIN_IMAGES` constant-preserved grep check)

## Decisions Made

- `select_al_frames` resolves each session's domain from `video_inventory.csv` internally (no `domain` parameter in the frozen contract signature) rather than requiring the caller to supply it.
- Candidate scoring reuses `detect.detect_video`'s full sequential decode+detect loop per pool clip and then subsamples a coarse, evenly-spaced grid (capped at 12 candidates per clip, mirroring `frames._MAX_FRAMES_PER_CLIP`'s "no clip dominates" ceiling) rather than building a new seek-based per-timestamp inference path — a deliberate cost/simplicity trade-off explicitly directed by the plan's own action text ("reusing `detect.detect_video`'s batching, not a new inference path"). Every frame of every pool clip is still decoded and detected even though only a subset becomes a candidate; documented as a known runtime cost, not fixed in this plan.
- Per-diversity-group allocation floors any non-empty group to at least 1 frame once `target > 0` (mirroring `frames.sample_training_frames`'s own floor/ceiling clamp, which likewise does not guarantee an exact target-sum total) rather than letting `_allocate_proportional`'s raw rounding leave a small group at zero.
- `validate_coco`'s new `min_images`/`max_images` keyword arguments default to `None` and are resolved from the module-level `_MIN_IMAGES`/`_MAX_IMAGES` globals *inside* the function body, not as Python parameter defaults evaluated once at def-time — necessary so `tests/test_cv_dataset.py::small_bounds`'s existing `monkeypatch.setattr(dataset, "_MIN_IMAGES", 2)` fixture (used by nine pre-existing tests) keeps working unchanged.

- **Issue:** The plan's `read_first` note states `FrameSampleManifest` "carries the per-frame domain after plan 02.2-02" — it does not; neither `FrameSample` nor `FrameSampleManifest` had a `domain` field anywhere in the actual codebase (verified via `git log`/grep against `frames.py`). `validate_coco(coco_dir, manifest)` has no `config` parameter, so per-domain box counting has no other source of truth for which domain each sampled frame belongs to.
- **Fix:** Added `domain: str = "drone"` to `FrameSample` (default preserves the single-domain Phase-2.1 shape for every pre-existing construction site), set explicitly from `sample_training_frames`'s own `domain` argument, and serialized/deserialized it in `write_manifest`/`read_manifest` (with a `row.get("domain", "drone")` fallback on read for manifests written before this field existed).

**2. [Rule 1 - Bug] Fixed def-time-evaluated keyword defaults in `validate_coco`**
- **Found during:** Task 3, immediately after adding `min_images`/`max_images` with `= _MIN_IMAGES`/`= _MAX_IMAGES` as literal parameter defaults

- **Fix:** Changed the parameter defaults to `None` and resolved `resolved_min_images`/`resolved_max_images` from the module globals inside the function body instead, restoring monkeypatch-ability.
- **Files modified:** `src/flag_football_ep/cv/dataset.py`

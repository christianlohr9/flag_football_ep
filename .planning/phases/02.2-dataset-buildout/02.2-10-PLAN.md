| project → hackathon participants | Everything in a bundle leaves the project's control |
| private labels → shipped archives | The test set's value depends on its labels never shipping |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-2.2-28 | Information Disclosure | test-kind bundle | mitigate | `build_bundle` raises when a test bundle's content table contains any label-bearing reference file; a test asserts the refusal |
| T-2.2-29 | Information Disclosure | PII frames/crops in bundles | mitigate | Bundles are built under the gitignored `data/bundles/` tree; the German README states the usage restriction (internal, purpose-bound, deletion after the event) per the federation approval |
| T-2.2-30 | Tampering | bundle contents | mitigate | Content hash over sorted (path, sha256) pairs via `dataset_hash`; the hash is published in docs/hackathon-bundles.md so a modified archive is detectable |
| T-2.2-31 | Repudiation | baseline claims | mitigate | Every rate published with `k/n`; the scoring script reproduces the documented number from the shipped tracks |

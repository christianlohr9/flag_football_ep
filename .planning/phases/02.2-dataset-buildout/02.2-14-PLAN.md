## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local machine → OTC OBS | PII-bearing bundles leave the machine |
| environment → tracked config | Credentials must not cross this line |
| bucket policy → the public internet | A misconfigured bucket exposes player footage |

<objective>
Run the first active-learning selection: draw the iteration-1 frames from the pool with the
uncertainty + diversity selector, prelabel them with the fine-tuned detector, and push them to CVAT
in weekend-sized tasks so the user's labelling block (D-16) starts from confirmation work rather
than blank frames.

Purpose: this is the plan that spends the user's scarcest resource — attention. Everything here is
about making the labelling session as short and as targeted as possible.
Output: a selection manifest, CVAT tasks ready to label, and the German record of what was selected
and why.
</objective>

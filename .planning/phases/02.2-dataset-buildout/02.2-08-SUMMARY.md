## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] `export_track_crops` let referee-labeled rows from flip-noise tracks into `index.csv`**
- **Found during:** Task 3 (running the real crops export against the pilot session's tracking Parquet)
- **Issue:** The track-level referee filter only inspected a track's first frame-sorted row. ~55 tracks in the real session flip `class_name` mid-track (known detector noise); a track that starts `player` can still have some sampled frames labeled `referee`. The first real run produced 115 `referee` rows in `index.csv`, violating the plan's `<behavior>` contract ("Only `class_name == "player"` tracks are cropped... referees are skipped") and its acceptance criterion ("No row of the index has `class_name == "referee"`").
- **Fix:** Added a per-sampled-row `class_name != "player"` check inside the existing per-track loop, in addition to the track-level first-row screen (kept as a cheap fast-path for wholly-referee tracks).
- **Files modified:** `src/flag_football_ep/cv/export.py`, `tests/test_cv_export.py`
- **Verification:** New regression test `test_export_track_crops_skips_referee_labeled_rows_within_a_flip_noise_player_track`; real re-export confirmed 0 `referee` rows (`awk -F, '$6=="referee"' index.csv | wc -l` -> 0) vs. 115 before the fix.
- **Committed in:** `be1e9e1`

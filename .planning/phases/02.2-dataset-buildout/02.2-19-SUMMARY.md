## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Fixed a false-positive heading-match footgun in inline cross-references**
- **Found during:** Task 2 (writing docs/dataset-card.md, running its structural tests)
- **Issue:** `docs/dataset-card.md` used inline references like `` `## Split-Methodik` `` (the
  literal heading string, in backticks) to point readers at other sections. The shared
  `_section()` test helper (used by `tests/test_phase22_docs.py` and
  `tests/test_cv_gate_artifacts.py`) extracts a section via a plain `text.index(heading)` --
  the first occurrence of that literal string, not necessarily the real `##`-prefixed heading
  line. Because the inline reference appeared earlier in the file than the actual heading, two
  new tests (`test_dataset_card_states_clip_level_split_rule_and_reason`,
  `test_dataset_card_limitations_name_at_least_four`) extracted the wrong slice and failed.
- **Fix:** Replaced all inline heading-style references (`` `## Split-Methodik` ``, `` `## Bekannte
  Limitierungen` ``, `` `## Provenienz` ``, `` `## Quellen` ``, `` `## Eingefrorene
  Evaluierungs-Ground-Truth` ``) with quoted plain text (e.g. „Split-Methodik") that reads
  identically to a human but no longer collides with the heading-extraction helper.
- **Files modified:** `docs/dataset-card.md`
- **Verification:** `uv run pytest tests/test_phase22_docs.py -x -q` -- 40 passed (was failing
  on 2 tests before the fix)
- **Committed in:** `27eaf38` (Task 2 commit)

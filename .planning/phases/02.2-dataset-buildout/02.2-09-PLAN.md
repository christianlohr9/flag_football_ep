                 _MIN_IMAGES = 250, _MAX_IMAGES = 600  (Phase-2.1 single-domain band)

Selection design (02.2-RESEARCH.md Pattern 1):
  uncertainty: zero detections in a frame scores 1.0 (a domain-shift miss is the strongest signal);
               otherwise mean |confidence - threshold| — small margins mean the model is unsure
  diversity:   two-level "group, allocate per group, then rank within group" on
               (domain, session_id, stratum_id, field_zone_bucket) — never a flat sort by score

  <behavior>
    - `frame_uncertainty_score` returns 1.0 for an empty detection set, and a value in [0, 1) that decreases as confidences move away from the threshold
    - `select_al_frames` never returns a frame from a clip whose `role` is `frozen_eval`
    - Selection is stratified: no stratum receives more than its proportional share plus one, and every stratum with candidates receives at least one frame when `target` exceeds the stratum count
    - Iteration 2 excludes every frame already selected in iteration 1 (read from the iteration-1 manifest)
    - The same `seed` and inputs produce a byte-identical manifest
    - An empty candidate pool raises `ActiveLearningError` naming the domain
  </behavior>
  <action>
    Implement selection as: build the candidate pool from `frames.clip_paths(..., domain=...)`
    restricted to `role = pool` clips via `frames.read_eval_split`; run the fine-tuned detector over
    a coarse frame grid per clip (reusing `detect.detect_video`'s batching, not a new inference
    path); score each sampled frame with `frame_uncertainty_score`; group candidates by
    `diversity_key` = `(domain, session_id, stratum_id, field_zone_bucket)` where the zone bucket is
    a coarse thirds-of-frame band on the mean detection foot point (fall back to a single bucket
    when no detections exist); allocate the target across groups with `_allocate_proportional`; and
    take the highest-uncertainty frames within each group. Enforce a per-clip cap so no single clip
    dominates (reuse the spirit of `_MAX_FRAMES_PER_CLIP = 12`).

    Persist the result with the `write_manifest` idiom: iteration number, seed, target, per-frame
    records (`session_id`, `domain`, `clip_number`, `frame_index`, `timestamp_s`, `uncertainty`,
    `diversity_key`), and the ids of previously selected frames that were excluded. Extract the
    selected frames to `out_dir` via `frames.extract_frames`.

    Write tests/test_cv_active_learning.py against synthetic detections (no model, no video where
    avoidable — monkeypatch the detection seam as tests/test_cv_detect_infer.py does), covering
    every behaviour above.
  </action>

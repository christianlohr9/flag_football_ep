## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] `*.dvc` glob pattern in the raw-video guard matched the `.dvc/` directory itself**
- **Found during:** Task 3, first run of `test_no_dvc_file_tracks_raw_video`
- **Issue:** `REPO_ROOT.rglob("*.dvc")` glob-matches the literal `.dvc` directory (the `*` in the pattern matches a zero-length prefix), causing `path.read_text()` to raise `IsADirectoryError` instead of iterating actual `.dvc` pointer files
- **Fix:** Added `path.is_file()` to the filter before reading
- **Files modified:** tests/test_dvc_layout.py
- **Verification:** `uv run pytest tests/test_dvc_layout.py -q` passes
- **Committed in:** 51e2ca3 (Task 3 commit)

**2. [Rule 3 - Blocking] `CvSettings`'s 5 new required fields broke every direct constructor call and hand-written `[cv]` TOML fixture in the test suite**
- **Found during:** Task 2, full-suite verification (`uv run pytest tests -q`)
- **Issue:** Adding 5 fields to `CvSettings`/`_CV_KEYS` is a breaking dataclass change. 16 test files construct `CvSettings(...)` directly (keyword args, no defaults), `tests/test_config.py`'s `MINIMAL_TOML` fixture and `tests/test_pipeline_ingest.py::_write_toml_config`/`tests/test_cli_report.py::_config_to_toml` hand-write a `[cv]` TOML block -- none of these are in the plan's `<files>` list, but all became broken (`TypeError: missing 5 required positional arguments` or `ConfigError: missing required key`) the moment `config.py` changed
- **Fix:** Added the 5 new fields (with test-appropriate placeholder values matching the checked-in `ffep.toml` pattern) to every affected call site via a scripted regex pass, then hand-verified two hand-written TOML string builders separately
- **Files modified:** tests/test_config.py, tests/test_pipeline_ingest.py, tests/test_cli_report.py, tests/test_cv_continuity.py, tests/test_cv_cvat.py, tests/test_cv_detect_infer.py, tests/test_cv_detect_train.py, tests/test_cv_overlay.py, tests/test_cv_radar.py, tests/test_cv_registry.py, tests/test_cv_teams.py, tests/test_cv_track.py, tests/test_model_evaluate.py, tests/test_model_experiments.py, tests/test_model_registry.py, tests/test_model_score.py, tests/test_model_train.py, tests/test_reports_own_team.py
- **Verification:** `uv run pytest tests/test_cli_run.py tests/test_cli_report.py -q` (the two hand-written-TOML files) -- 0 failures/errors after the fix. A comprehensive suite run excluding only the two heaviest real-training files (`test_model_train.py`, `test_cv_detect_train.py`, both individually confirmed via the same scripted fix) showed no additional failures through the region of the suite that exercises every affected file.
- **Committed in:** 74468b4 (Task 2 commit, bundled with the schema change that caused it)

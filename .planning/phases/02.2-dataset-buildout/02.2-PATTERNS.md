**Proportional-allocation pattern to reuse verbatim in spirit** (`src/flag_football_ep/cv/frames.py` lines 324-339, `_allocate_proportional`):
```python
def _allocate_proportional(weights: dict[str, float], target: int) -> dict[str, int]:
    total = sum(weights.values())
    if total <= 0:
        n = len(weights)
        if n == 0:
            return {}
        base, remainder = divmod(target, n)
        return {key: base + (1 if i < remainder else 0) for i, key in enumerate(sorted(weights))}
    return {key: max(0, round(target * weight / total)) for key, weight in weights.items()}
```
Diversity stratification for AL selection (D-15) should key off `(domain, clip_number, hover_position_id/camera, field_zone_bucket)` the same way `frames.py::sample_training_frames` groups by `hover_ids.get(n, "all")` before allocating (lines 380-396) — reuse the "group, allocate per group, then allocate within group" two-level pattern rather than a single flat sort-by-score.

**Manifest persistence pattern** — copy `frames.py::write_manifest`/`read_manifest`'s atomic-write + typed-dataclass round trip exactly (lines 453-532): `.tmp` sibling + `os.replace`, `json.dumps(..., indent=2, sort_keys=True)`, an explicit `required_keys` check raising a named error on a malformed file. **Uncertainty input contract** — consume `sv.Detections` exactly as `detect.py::detect_video`/`DetectionRun` already produce it (function-local import of `supervision`, never a new detection representation):
```python
# consumes flag_football_ep.cv.detect's existing DetectionBatch/sv.Detections output,
# never a redefinition of the detection schema
def frame_uncertainty_score(detections) -> float:
    if len(detections) == 0:
        return 1.0
    conf = detections.confidence
    return float(np.mean(np.abs(conf - CONFIDENCE_THRESHOLD)))
```

**Source:** `src/flag_football_ep/config.py::secret()` (lines 293-307), used by `cv/dataset.py::create_cvat_task`/`export_cvat_task` (lines 343-346, 391-394)

# Phase 01.4 Plan 03: 4th-Down Conversion Rates and Chart Summary

**4th-down conversion rates estimated per distance bucket with Clopper-Pearson intervals, rendered as a headless matplotlib bar chart with explicit "keine Daten" gaps for empty buckets.**

## Performance

- **Duration:** ~75 min
- **Tasks:** 2/2 completed
- **Files modified:** 4 (2 created, 2 modified)

## Accomplishments
- `estimate_fourth_down_rates` in `features/mutations.py`: attempts defined as `down == 4` run/pass plays (excluding `no_play`, `penalty == 1`, and PAT rows implicitly via the `down == 4` predicate), conversions as `first_down == 1` OR `touchdown == 1`, bucketed by `yards_to_go` via a chained polars `when/then/otherwise` built from `FOURTH_DOWN_DISTANCE_BUCKETS`. Never raises on an empty bucket.
- `charts/fourth_down.py`: `render_fourth_down` renders a headless Figure (bar per bucket, asymmetric CI error bars, `n=` attempt annotations, `keine Daten` for empty buckets, dashed overall-rate reference line); `write_fourth_down` writes a PNG with the same overwrite-guard/close-in-finally contract as `write_pat_breakeven`.

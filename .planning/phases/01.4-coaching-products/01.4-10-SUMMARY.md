# Phase 01.4 Plan 10: Tendency Bar Chart Renderers Summary

**Two generic, Figure-returning bar renderers (`render_share_bars`, `render_epa_bars`) that the opponent tendency and own-team efficiency reports both embed, following the `charts/pat_breakeven.py` headless-Agg convention.**

## Performance

- **Duration:** ~35 min (across several resumed sessions due to unrelated machine-sleep interruptions)
- **Tasks:** 2/2 completed
- **Files modified:** 2 (both created)

## Accomplishments
- `render_share_bars`: sorts by share descending, fixes the x axis to `(0, 1)` formatted as percentages, greys out muted (thin-sample) rows with an explicit axes note, annotates every bar with `n=K`, and truncates to `max_bars` with an omitted-count note
- `render_epa_bars`: signed horizontal bars around a zero reference line, symmetric x limits from the data's max absolute value, positive/negative/muted colour rules where muting always outranks sign, and null-valued rows dropped (never plotted as zero) with their count annotated
- Both functions share one set of module-private helpers (`_figsize`, `_empty_placeholder`, `_annotate_n`, `_draw_muted_note`, `_draw_omission_note`) built once in task 1 and reused, not duplicated, in task 2
- An empty aggregation frame renders a `keine Daten` placeholder Figure and returns normally in both functions, so a batch report run survives one empty section

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| mixed-source canonical corpus → per-opponent scouting conclusions | sections built on Hudl-only fields silently mixed with PBP-only games would state tendencies the data cannot support |
| aggregate cells → plain-language summary sentences | a sentence asserts something a table merely shows; an unqualified sentence from three plays is the sharpest failure mode in this phase |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-1.4-31 | Tampering (misrepresentation) | a summary sentence generated from a thin cell | mitigate | `top_tendency_sentences` only considers cells with `n >= MUTED_MIN_N`, weights the score by `sqrt(n)`, and falls back to a single explicit "too thin" sentence; asserted in tests |
| T-1.4-32 | Tampering (data integrity) | charted-only sections silently computed over PBP games where the field is null | mitigate | `charted_only` restricts the frame and `section_basis` is taken from the restricted subset, so each section states the games it truly used |
| T-1.4-33 | Tampering (data integrity) | rows with a null score state or null formation silently dropped, breaking play-count reconciliation | mitigate | nulls become an explicit `unbekannt` group; a test asserts the play-call table's total equals the non-PAT play count |
| T-1.4-34 | Tampering (definition drift) | the report's 4th-down conversion definition drifting from the decision chart's | mitigate | the same attempt/conversion and PAT predicates as `estimate_fourth_down_rates` / `estimate_pat_baselines`, pinned by a test on the report side asserting the touchdown-without-first-down case |
| T-1.4-35 | Denial of service | an opponent with zero film aborting the batch run | mitigate | `build_opponent_data` returns empty sections plus notices for an absent team; asserted in tests |

## Decisions Made
- **`select_autoescape` extension list includes `"j2"`.** The plan's interface comment showed `select_autoescape(["html", "htm", "xml"])` verbatim, but `select_autoescape` matches only a template name's final suffix. Every template in this package is named `*.html.j2` for the mixed HTML/Jinja-source naming convention already implied by the plan's own file paths (`base.html.j2`, etc.), so the final suffix is always `.j2`. Without adding `"j2"` to the enabled list, autoescape would be silently `False` for every real template this project ships, defeating the whole point of Pattern 2 and the T-1.4-05 threat mitigation. Caught by a dedicated regression test (`test_autoescape_is_truthy_for_real_dotj2_template_names`) before it could reach a builder module.
- **`write_report_run` clears a stale same-day `run_dir` first.** The plan's own Code Examples snippet used `mkdir(parents=True, exist_ok=True)` without clearing prior contents, which — combined with the plan's own required test ("a second `write_report_run` call with a different file set leaves `latest/` holding only the newer set") — would fail on a same-day rerun: old files from the first call would still be sitting in `run_dir` and get copied into `latest/` alongside the new ones. Clearing `run_dir` before writing preserves "one call = one complete run" and satisfies the plan's own acceptance test.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] `select_autoescape` extension list missing `"j2"`, leaving autoescape off for every real template**
- **Found during:** Task 1 (writing `tests/test_reports_render.py`'s escaping assertion)
- **Issue:** `select_autoescape(["html", "htm", "xml"])` checks only a template name's final suffix; `base.html.j2`'s final suffix is `.j2`, not `.html`, so autoescape evaluated to `False` and a `<script>` payload rendered literally instead of escaped — the exact T-1.4-05 threat this plan's threat model requires mitigated.
- **Fix:** Added `"j2"` to the enabled-extensions list passed to `select_autoescape`, with an inline docstring explaining why (the `*.html.j2` naming convention every template in this package uses).
- **Files modified:** `src/flag_football_ep/reports/render.py`, `tests/test_reports_render.py` (added `test_autoescape_is_truthy_for_real_dotj2_template_names` regression test)
- **Verification:** `pytest tests/test_reports_render.py -x -q` — escaping test and new regression test both pass
- **Committed in:** `d2e9c21` (Task 1 commit)

**2. [Rule 1 - Bug] `write_report_run` merged same-day reruns into `latest/` instead of replacing**
- **Found during:** Task 3 (writing the "second call replaces, doesn't merge" test the plan's own `<action>` requires)
- **Issue:** `run_dir.mkdir(parents=True, exist_ok=True)` left a prior same-day run's files in place; a second call with a different file set left both old and new files in `run_dir`, which then all got copied into `latest/` via `shutil.copytree`, violating the plan's own required behavior and the "atomic at directory granularity" success criterion.
- **Fix:** `write_report_run` now `shutil.rmtree`s an existing same-day `run_dir` before writing this call's files into a fresh one, so one call is one complete, non-accumulating run.
- **Files modified:** `src/flag_football_ep/reports/render.py`
- **Verification:** `pytest tests/test_reports_render.py -x -q` — `test_second_run_replaces_latest_rather_than_merging` passes
- **Committed in:** `988fde0` (Task 3 commit)

**3. [Rule 3 - Blocking] Minimal `base.html.j2` created in Task 1, ahead of Task 2's full build**
- **Found during:** Task 1 (the plan's own required tests for `build_environment`/`render_page` load and render `base.html.j2`, which does not otherwise exist until Task 2)
- **Issue:** Task 1's acceptance criteria require `get_template("base.html.j2")` to succeed and `render_page("base.html.j2", title=...)` to produce escaped output, but the plan assigns creating that file to Task 2 — a strict per-task verification gate would fail on Task 1 without it.
- **Fix:** Created a minimal placeholder `base.html.j2` (bare `<!DOCTYPE html>` shell with a `title` block and `content` block) in Task 1, sufficient for Task 1's tests; Task 2 then replaced it wholesale with the full tablet/print-styled version per its own spec.
- **Files modified:** `src/flag_football_ep/templates/base.html.j2` (created in Task 1, fully rewritten in Task 2)
- **Verification:** `pytest tests/test_reports_render.py -x -q` passes after both Task 1 and Task 2
- **Committed in:** `d2e9c21` (Task 1 commit, minimal stub), `23eb755` (Task 2 commit, full template)

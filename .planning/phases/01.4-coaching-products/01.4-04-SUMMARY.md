# Phase 01.4 Plan 04: WP Review Chart Summary

**Per-game win-probability review chart (`charts/wp_review.py`) with top-k \|wpa\| plus
every scoring/turnover play annotated, capped at 8 markers, and a synthetic-clock
disclosure duplicated in the title and an in-axes note.**

## Accomplishments

- `select_wp_annotations`: a pure, tested polars function selecting the top-k `|wpa|` swings
  plus every scoring/turnover play, ranking scoring/turnover rows ahead of swing-only rows
  when the `WP_ANNOTATION_MAX` cap trims the union, sorted by `play_id` with a short
  `annotation_label` (e.g. `P23 TD GER +0.18`).
- `render_wp_review`: headless (Agg-backend), returns a `Figure` with the home-team WP curve
  fixed to `[0, 1]` y-limits, a 50% reference line, annotated markers, and a synthetic-clock
  disclosure that appears in both the title suffix and a dedicated in-axes `Hinweis` text
  when `synthetic_clock=True` (the default) -- and disappears entirely when `False`.
- `write_wp_review`: write-once-unless-`overwrite` PNG writer matching
  `write_pat_breakeven`'s contract (`mkdir(parents=True)`, `savefig` in `try`,
  `plt.close(fig)` in `finally`).
- A game with fewer than two non-null `home_wp` rows renders a `keine WP-Daten für dieses
  Spiel` placeholder instead of raising (T-1.4-14 DoS mitigation).

## Decisions Made

- Built `annotation_label` via a small Python loop over the (at most 8) candidate rows
  instead of a chained polars string expression, so the signed `wpa` always renders to
  exactly two decimals (`+0.18`) -- `pl.Expr.round(2).cast(Utf8)` truncates trailing zeros
  (`0.20` -> `"0.2"`), which would have broken the plan's example format.
- `select_wp_annotations` computes `is_event`/`abs_wpa` as temporary `_`-prefixed columns,
  dropped before returning, to keep the ranking-then-cap logic a single polars pipeline
  rather than a Python sort.
- Kept `synthetic_clock` defaulting to `True` end-to-end (matches the plan's interface
  contract and `prepare_wp_data`'s only production path), so a caller must explicitly pass
  `synthetic_clock=False` to get the "real clock" axis label and to suppress the `Hinweis`
  note -- there is no code path that silently drops the disclosure.

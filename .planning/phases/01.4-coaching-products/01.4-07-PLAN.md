<objective>
Turn the annotated WP curve from plan 04 into REQ-S1-15's per-game review product: one
standalone HTML page per game, with the chart, a short swing table, an explicit synthetic-clock
notice, and a filename that is safe to write.

Purpose: the WP chart alone is an image. The review page is what the staff opens next to the
film — curve on top, the plays that moved it listed underneath with their WP change, so a
swing on the chart can be found on the tape.
Output: `reports/wp_review.py` and `templates/wp_review.html.j2`.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `game_id` (derived from an analyst-controlled export filename) → output filename under `reports/` | the untrusted half of the write path |
| charted team codes / play labels → HTML page | source-derived strings interpolated into a document |
| synthetic WP timeline → coaching conclusion | a curve that looks time-based but is play-indexed |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-1.4-26 | Tampering | path traversal through a crafted `game_id` in `wp_review_filename` | mitigate | `game_slug` allow-lists `[A-Za-z0-9._-]`, strips leading dots, re-validates against `GAME_SLUG_PATTERN` and raises on an empty result; plan 02's `write_report_run` rejects separator-bearing keys as a second layer |
| T-1.4-27 | Tampering | markup injection via a game id or team code | mitigate | plan 02's `select_autoescape`; asserted with a `<b>` payload rendering as `&lt;b&gt;` |
| T-1.4-28 | Repudiation / misrepresentation | synthetic timeline read as real clock data | mitigate | a `.warning-block` in the page plus the chart's own title suffix and in-axes note (plan 04); asserted for both flag values |
| T-1.4-29 | Denial of service | one game with no WP data aborting a batch of per-game pages | mitigate | fewer than two non-null `home_wp` rows renders a `keine WP-Daten` page instead of raising |
| T-1.4-30 | Information disclosure | n/a | accept | this page carries team codes and play numbers, no player names; the `reports/` gitignore entry (plan 01) covers the tree regardless |

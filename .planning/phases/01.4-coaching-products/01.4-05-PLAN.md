    Add `RateCell`, `rate_table` and `share_table` to `reports/aggregate.py`.

    `RateCell` is a frozen dataclass with `label`, `n`, `successes`, `rate`, `ci`, `muted`, plus
    a `text` property returning the German display string CONTEXT locks — the rate as a rounded
    percentage followed by the count in parentheses, e.g. `78% Pass (n=9)` — and returning
    `keine Daten` when `n == 0`. Document that `muted` is `n < MUTED_MIN_N` and that the
    consumer's job is to render muted cells greyed, never to drop them.

    `rate_table(df, group_cols, success, *, label_col="label") -> pl.DataFrame`: group `df` by
    `group_cols`, aggregate `pl.len()` as `n` and the boolean `success` expression's true count
    as `successes`, then add `rate = successes / n`, `ci_low`/`ci_high` from
    `binomtest(successes, n).proportion_ci()` per row, and `muted = n < MUTED_MIN_N`. Compute
    the interval per row in a small Python loop over the aggregated (already tiny) frame — the
    aggregation stays in polars, only the scipy call is per row. `rate` and both CI bounds are
    null when `n == 0`. Groups are returned sorted by `group_cols` so table output is
    deterministic across runs.

    `share_table(df, group_cols, category_col) -> pl.DataFrame`: the distribution of
    `category_col`'s values within each `group_cols` group — one row per
    (group, category) pair with `n` (rows in that category), `group_n` (rows in the group),
    `share = n / group_n`, Clopper-Pearson `ci_low`/`ci_high` for that share, and
    `muted = group_n < MUTED_MIN_N`. Null `category_col` values are excluded from the numerator
    but reported as their own `"unbekannt"` category row rather than silently vanishing, so a
    distribution always sums to 1 within a group. Sorted by `group_cols` then `share`
    descending, so the dominant tendency is the first row a template renders.

    Both functions return an empty frame with the full declared schema (not a bare empty frame)
    when `df` is empty, and raise nothing — a report section with no data must render a
    "keine Daten" block, not crash the run.

    Extend `tests/test_reports_aggregate.py` with `TestRateCell`, `TestRateTable` and
    `TestShareTable` classes asserting: `RateCell.text` formats as `NN% Label (n=K)` and as
    `keine Daten` at `n == 0`; `muted` flips exactly at `MUTED_MIN_N`; `rate_table` produces one
    row per group with correct `n`/`successes`/`rate`; `ci_low <= rate <= ci_high` for a
    populated group; a group with `successes == n` still yields a CI whose upper bound is 1.0
    and whose lower bound is below 1.0 (the extreme-rate case a normal approximation would get
    wrong); `rate_table` output is sorted by `group_cols`; `share_table` shares sum to 1.0
    within each group including the `unbekannt` category; `share_table` orders rows by share
    descending within a group; both return a correctly-schema'd empty frame for an empty input
    and raise nothing.

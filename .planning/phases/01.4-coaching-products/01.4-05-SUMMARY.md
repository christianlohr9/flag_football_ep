# Phase 01.4 Plan 05: Shared Report Aggregation Vocabulary Summary

**`flag_football_ep.reports.aggregate` module: locked field-zone/score-state/distance bucketing via chained polars `when` expressions, and honest rate/share tables where every cell carries its sample size, a Clopper-Pearson confidence interval, and an explicit thin-sample flag.**

- **Completed:** 2026-08-21

## Accomplishments
- `add_report_buckets` adds `field_zone` (3 zones + explicit red zone over `yardline_50`), `score_state` (three margin buckets, ±6 as the locked close-game band), and `distance_bucket` (the same boundaries `estimate_fourth_down_rates` uses) via chained `pl.when(...).then(...).otherwise(...)` expressions built from tuple constants -- one source of truth per bucket set
- `RateCell`/`rate_table` and `share_table` give every rate and every share cell its `n`, a Clopper-Pearson `ci` (via `scipy.stats.binomtest`, never a hand-rolled normal approximation), and a `muted` flag at `n < MUTED_MIN_N` -- the CONTEXT-locked "shown, never hidden" thin-sample rule
- `share_table` reports null category values as an explicit `"unbekannt"` row rather than silently dropping them, so a distribution always sums to 1.0 within a group
- `section_basis` produces the German `Datenbasis: {n} Spiele ({sources}), {n} Plays` one-liner every report section prints, with correct singular `1 Spiel` handling and a `"keine Daten"` fallback for empty input
- `charted_only` is the graceful-degradation filter for Hudl-only sections (formation/route/coverage), raising `ValueError` naming the column on a typo rather than silently returning an empty section
- Every aggregation function returns a schema-correct empty frame instead of raising on empty input

## Decisions Made
- **`rate_table`'s `label_col` parameter produces an actual output column.** The plan's interface comment listed `rate_table`'s output columns as "group cols + n, successes, rate, ci_low, ci_high, muted" with no stated behavior for the `label_col` parameter beyond its default value `"label"` in the signature. Declaring a parameter that does nothing would leave a locked interface contract dead on arrival for the plan 08/09 builders that consume it. Concatenating `group_cols` values with `" / "` into a column named by `label_col` gives those builders a ready-made display label for constructing `RateCell` instances directly from each row.
- **`share_table`'s category output column keeps the caller's `category_col` name** rather than a generic `"category"` column, so a builder already holding the column name (e.g. `"off_play"`) can filter or join on it without an extra rename step.

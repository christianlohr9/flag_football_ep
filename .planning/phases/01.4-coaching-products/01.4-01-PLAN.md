    "canonical_player": pl.Utf8}` and `load_player_mapping(path) -> pl.DataFrame`, shaped

    has no `source` column and is an unverified single-source dump — RESEARCH assumption A3).
    Record that reasoning in the function docstring.

    `_GROUP_OPPONENTS_SCHEMA = {"canonical_team": pl.Utf8, "team_name": pl.Utf8}` and
    `load_group_opponents(path) -> pl.DataFrame`, shaped like `load_sportapp_games` (the
    simplest loader in the file — read and return, no validation) except it additionally
    rejects duplicate `canonical_team` values with a `ValueError`, the same way
    `load_final_scores` rejects duplicate `game_id`.

    `PlayerMappingResult`, a frozen dataclass with `frame: pl.DataFrame` and
    `unmapped: list[str]`, and `map_players(df, mapping, source, columns) ->
    PlayerMappingResult`. Copy `map_teams`'s `source_map = mapping.filter(pl.col("source") ==
    source)` filter, its `lookup = dict(zip(...))` construction and its unmapped-collection
    loop verbatim — but instead of raising `UnmappedTeamError`, apply
    `pl.col(col).replace(lookup)` for every requested column that exists in `df` (polars
    `replace` already leaves a key absent from the mapping untouched, which is exactly the
    locked "unmapped names appear as-is" behaviour) and return a `PlayerMappingResult` whose
    `unmapped` is the sorted list of distinct labels with no mapping entry. Never raise on an
    unmapped label, never drop the row, never null the value. State in the docstring that this
    is the one deliberate divergence from the `map_teams`/`map_competition_tier`
    raise-on-unmapped precedent, and why (CONTEXT.md: "the report never breaks on an unmapped
    name", the caller renders `unmapped` as a prominent warning block).

    `map_players` must handle `columns` entries absent from `df` by skipping them (same guard
    as `map_teams`) and must preserve row count and row order.

    In `tests/test_reference.py` add, mirroring the existing `test_map_teams_*` style:
    duplicate-pair rejection for `load_player_mapping`; duplicate-`canonical_team` rejection

    distinct label as unmapped and raises nothing; `map_players` preserves height and order;
    `map_players` skips a column name that is not in the frame.

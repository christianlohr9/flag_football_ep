explicit decision in that plan, not a silent skip.

## Consequences for planning

- **LOGO fold count:** 247 folds per model (one per unique `game_id`) — plan 01.3-04 must
  budget for exactly this many XGBoost fits per model per LOGO measurement pass.
- **Recency weighting:** `game_date` is 100% null across all three sources present in the
  real corpus — the recency-weighting experiment (REQ-S1-09) cannot use `game_date` for
  any source as-is; plan 01.3-07 must either defer this candidate explicitly or design an
  alternate chronological signal, not silently degrade to a no-op weight of 1.0.
- **IFAF real-clock experiment:** viable exactly as scoped — `game_clock_ms` is 100%
  populated for `ifaf` (3,191/3,191 rows) and 0% populated everywhere else, giving a clean
  IFAF-only comparison with no cross-source contamination risk.

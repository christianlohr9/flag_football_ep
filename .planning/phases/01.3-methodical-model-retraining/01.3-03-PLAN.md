<objective>
Add the MLflow model registry layer: register a production model version, promote it to the
`champion` alias through an explicit `ffep promote` step, and make `ffep score` resolve that
alias instead of silently following the newest FINISHED run. Retire the stale fixed-name
pickles in `models/` at the same time.

Purpose: CONTEXT §"PAT baselines & model versioning" locks the registry as the primary
versioning mechanism and requires an explicit promotion step — `ffep score` must never pick up
an unreviewed exploratory run as if it were production-ready. Phase success criterion 5
("`ep_model.pkl` is never silently overwritten again") is closed here.

Output: `model/registry.py`, champion-alias resolution in `score.py`, `ffep promote`,
retired legacy pickles, and the registry test module.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI flag -> MLflow URI | `--run` (promote) and `--ep-run`/`--wp-run` (score) reach `runs:/` and `models:/` URI strings |
| Registered-model name/alias -> `models:/` URI | Derived names and the `champion` alias are interpolated into registry lookups |
| Pickle file -> deserializer | `models/` contains untrusted-by-default pickles |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-1.3-07 | Tampering | `registry._validate_model_name` / `_validate_alias` | mitigate | `_IDENTIFIER_PATTERN = ^[A-Za-z0-9_-]{1,64}$` applied before any `models:/{name}@{alias}` interpolation; direct extension of the T-1.2-08 `_validate_run_id` mitigation, asserted by the `REJECTED_ALL` acceptance criterion |
| T-1.3-08 | Tampering | `cli.promote --run` | mitigate | `registry.promote` reuses `score._validate_run_id` (plain hex) before the id reaches `search_model_versions`; no path fragment can reach the store |
| T-1.3-09 | Elevation of Privilege | `score.resolve_run` default path | mitigate | Removing the newest-FINISHED fallback means an unreviewed run can no longer become the model `ffep score` loads; promotion is an explicit, human-invoked command (CONTEXT §Promotion) |
| T-1.3-10 | Tampering | `models/*.pkl` deserialization | mitigate | Legacy pickles moved to `models/legacy/` and documented as not loadable by the pipeline; `score.py` still never calls `pickle.load` (guarded by the existing `test_score_module_never_uses_pickle_load`) |
| T-1.3-11 | Repudiation | champion promotion | mitigate | Every promotion creates a registry alias record bound to a specific model version and run id, queryable in the MLflow UI — who/when is recoverable from the registry rather than inferred from file mtimes |
| T-1.3-SC | Tampering | package installs | mitigate | No package installs in this plan; RESEARCH `## Package Legitimacy Audit` records zero new external packages for this phase |
</threat_model>

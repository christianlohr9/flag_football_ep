<objective>
Replace the play-level `train_test_split(test_size=0.2, random_state=42)` in the shared EP/WP
training pipeline with a leave-one-game-out (LOGO) evaluation loop over `game_id`, and make
the shipped model a single refit on all games with the tuned parameters.

Purpose: REQ-S1-07 and project decision D-07. Plays from the same game currently land in both
train and test, so every reported metric is optimistically biased. CONTEXT §"Grouped-CV
protocol" locks LOGO (the maximal form of D-07) for measurement, a cheap grouped inner CV for
tuning, and one refit for the production artifact.

Output: `model/evaluate.py` with `run_logo`, grouped-CV constants in `hyperparams.py`, a
rewired `_train`/`_tune`, and the fold-disjointness test module.
</objective>

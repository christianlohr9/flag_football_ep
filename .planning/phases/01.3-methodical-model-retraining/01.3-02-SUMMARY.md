## Decisions Made

- **`game_date` recency-weighting risk surfaced, not resolved here:** the profile shows 100% null `game_date` across every real source. This is worse than RESEARCH's Pitfall 4 anticipated (a "some sources degrade" risk) — it is total absence in the current corpus. Documented explicitly in the profile's "Consequences for planning" so plan 01.3-07 makes an informed, explicit call (defer the candidate, or design an alternate chronological signal) rather than silently computing a no-op weight.
- **PAT baseline scope narrowed:** only `legacy` has `down == 0` rows under the existing predicate. Plan 01.3-06 needs to either scope PAT estimation to `legacy` or investigate whether `ifaf`/`legacy-sportapp` encode PAT attempts differently (e.g., a different down value) before assuming pooled data exists.
- **Tier assignment for ambiguous pairs:** `legacy` (gender null, competition name is the literal `"legacy"` placeholder) and `legacy-sportapp`/`FlagWC` (gender codes are raw numeric `"1"`/`"2"`, not decodable without a separate mapping, and both codes are present in that one pair) were both assigned `mixed-other` per the plan's explicit fallback rule — no unambiguous single-gender signal or competition name was available for either. `ifaf`/`IFAF World Flag 2026` was assigned `womens-international` — `gender` is unambiguously `"women"` and the competition name names an international World Flag tournament.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] Fixed three pre-existing test fixtures broken by the new required `ReferenceFiles.competition_tier` field**
- **Found during:** Task 2, running `.venv/bin/pytest -q` (full suite) per the plan's verification step
- **Issue:** `tests/test_model_score.py`, `tests/test_model_train.py`, and `tests/test_pipeline_ingest.py` each construct `ReferenceFiles(...)` (or an inline TOML string) directly rather than through `load_config()`. Adding `competition_tier` as a required dataclass field (per the plan's explicit instruction) made every one of those constructions fail with `TypeError: ReferenceFiles.__init__() missing 1 required positional argument`, and `test_pipeline_ingest.py`'s inline `ffep.toml` fixture (used by several `test_cli_run.py`/`test_pipeline_ingest.py` CLI tests) failed with `ConfigError: missing required key 'competition_tier'`.
- **Fix:** Added `competition_tier=tmp_path / "data" / "reference" / "competition_tier.csv"` (or the equivalent `data_root`-relative path) to each `ReferenceFiles(...)` call, and added `competition_tier = "..."` to the inline TOML fixture in `test_pipeline_ingest.py`'s `_write_toml_config`.
- **Files modified:** `tests/test_model_score.py`, `tests/test_model_train.py`, `tests/test_pipeline_ingest.py`
- **Verification:** `.venv/bin/pytest -q` (full suite) exits 0 after the fix, with no remaining `ReferenceFiles`/`ConfigError` failures.
- **Committed in:** `3228d98` (Task 2 GREEN commit)

**2. [Rule 1 - Bug] Cast the join-key mapping columns explicitly before the left join in `map_competition_tier`**
- **Found during:** Task 2, RED->GREEN cycle — `test_map_competition_tier_empty_mapping_raises` failed with `polars.exceptions.ComputeError: datatypes of join keys don't match - source: str on left does not match source: null on right`
- **Issue:** An empty `pl.DataFrame` built with `schema=[...]` (list of names, no explicit dtypes) infers `Null` dtype for every column. `map_competition_tier`'s contract explicitly requires raising `UnmappedCompetitionError` "including when `mapping` is empty" — an all-`Null`-typed empty mapping is a valid caller input under that contract, not an edge case to exclude.
- **Fix:** `map_competition_tier` now explicitly casts `mapping`'s `source`/`competition`/`tier` columns to `pl.Utf8` before the join, so an empty or loosely-typed mapping frame joins cleanly instead of raising a `ComputeError`.
- **Files modified:** `src/flag_football_ep/reference.py`
- **Verification:** `.venv/bin/pytest tests/test_reference.py -k competition_tier -q` passes all 9 tests.
- **Committed in:** `3228d98` (Task 2 GREEN commit)

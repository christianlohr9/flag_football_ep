## Sampling Rate

- **After every task commit:** Run `.venv/bin/pytest tests/test_model_train.py tests/test_model_score.py -q`
- **After every plan wave:** Run `.venv/bin/pytest -q` (the migration from `file:` to `sqlite:` tracking touches shared fixtures used across `test_model_train.py` and `test_model_score.py`, so both must stay green together)
- **Before `/gsd:verify-work`:** Full suite must be green, plus a manual check that `mlflow ui --backend-store-uri sqlite:///.../mlflow.db` renders the reliability-curve PNGs and registered-model aliases (MLflow UI browsability is an explicit CONTEXT requirement)
- **Max feedback latency:** 120 seconds

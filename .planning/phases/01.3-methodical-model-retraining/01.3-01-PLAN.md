<objective>
Move the MLflow tracking store from the deprecated local `file:` store to a local
SQLite-backed store, behind one shared helper module, and rewrite every test that
assumes the FileStore's on-disk run-directory layout.

Purpose: MLflow's model registry — the CONTEXT-locked source of truth for REQ-S1-11
("MLflow model registry is primary") — does not work against a `file:` tracking store.
This migration is a hard prerequisite for every registry-touching plan in this phase, and
it also removes the `MLFLOW_ALLOW_FILE_STORE` deprecation opt-in. Nothing about model
quality, features or evaluation changes here.

Output: `model/mlflow_store.py`, migrated `train.py`/`score.py`, migrated test suite,
updated `docs/pipeline.md`.
</objective>

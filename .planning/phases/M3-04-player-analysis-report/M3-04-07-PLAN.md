```python
frage_headings = re.findall(r"^## Frage \d+", text, re.MULTILINE)      # must stay == 6
stub_section = text[text.index("## Antworten"):]
stub_headings = re.findall(r"^### Frage \d+", stub_section, re.MULTILINE)   # must stay == 6
# plus an ordering assertion: Frage 3 < 4 < 5 < 6 < "## Was wir ohne Antwort liefern"
```

`^## Frage \d+` does not match a `####` heading and `^### Frage \d+` does not match `#### Frage 7`,
so a `## Zusatzfragen (…)` section containing `#### Frage 7/8/9` is invisible to both counters. The
ordering assertion uses `text.index(...)` on sections that all sit above this appended block, so
appending at the end of the file leaves it untouched.

Pitfall 2):

  both compute over `Data` rows 3001-4000. Same window, two names. Which is the right one, and
  should there be a Player-Analysis tab for every Set-Analysis camp?
- **Frage 8 — Was steckt in `Data!Y` (Spaltenkopf "B")?** His Air-Yards formula subtracts
  `SUMIF(Data!L, <QB-Name>, Data!Y)` — a term keyed on rows where `RECEIVED BY` is the QB himself.
  The column header is the single letter `B` and its meaning appears nowhere. Until it is answered
  our Air Yards omit the subtraction, which we state in the report.
- **Frage 9 — Wie füllst du die Drop-Spalte (`Data!W`)?** `Adj Comp %`, `adj Pass Yards` and
  `adj YPA` all key on it. Two sub-questions: is a drop marked as text (an `x`, a word) or as a
  number — his own `COUNTIFS(..., "*")` criterion counts **text only**, so numeric marks would be
  silently ignored by his own sheet — and does a drop also count as an incompletion in `Incs`
  (the Attempts-plus-Drops ambiguity already open under Frage 5)?

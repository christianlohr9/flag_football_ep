`plays_scored.parquet` instead of from a hand-maintained sheet, column for column, with his
definitions — the ones read out of his formula cells, not the ones a column name suggests.

charted `Data!O` extra; `Adj Comp %` / `adj Pass Yards` / `adj YPA` need a canonical `drop` column

column, so the page can print "nicht verfügbar (Drop-Spalte noch nicht kanonisch)" rather than a
number that looks computed.

presentation.
